# 第一部分：通用规范

## 1. 坐标系与单位

| 项目 | 规范要求 |
|------|----------|
| 坐标系 | **右手空间直角坐标系（Right-hand Cartesian）** |
| 模型比例 | **1:1** |
| 长度单位 | **毫米（mm）** |
| 地理坐标系 | **CGCS2000（2000国家大地坐标系）** |
| 高程基准 | **1985国家高程基准** |
| 坐标轴（通用） | **Z 轴向上，X 轴指向线路大里程方向，Y 轴垂直于线路** |
| 角度单位 | **度（decimal degrees）** |

### 1.1 接触网坐标系

| 项目 | 约定 |
|------|------|
| 原点 | 接触网支柱基础顶面中心 / 线路中心线轨面标高 |
| X 轴 | 沿线路方向（大里程为正） |
| Y 轴 | 垂直线路方向（面向大里程，左侧为正） |
| Z 轴 | 垂直向上 |

### 1.2 轨道坐标系

| 项目 | 约定 |
|------|------|
| 原点 | 线路中心线轨面高程点（各里程桩号） |
| X 轴 | 沿线路方向（大里程为正） |
| Y 轴 | 垂直线路方向（面向大里程，左侧为正） |
| Z 轴 | 垂直向上 |

## 2. 体系架构

接触网参数化建模以 **支柱** 为装配主体，通过配置参数决定挂载的子系统和协同样式，对外只暴露一个入口——**支柱整体装配**。

```
                    ┌──────────────────────────────────────┐
                    │        对外唯一入口                   │
                    │      MastAssembly(params)             │
                    │  「以支柱为主体，配置各子系统」         │
                    └──────┬───────────────────────────┬───┘
                           │ 根据配置参数派生              │
              ┌────────────┼──────────────┬──────────────┼──────────────┐
              ▼            ▼              ▼              ▼              ▼
         ┌────────┐ ┌──────────┐ ┌────────────┐ ┌──────────┐ ┌──────────────┐
         │ 支柱本体 │ │ 悬吊系统 │ │ 补偿系统   │ │ 拉线系统 │ │ 附加导线系统 │
         │ (必选)  │ │ (单/双臂)│ │ (可选)     │ │ (可选)   │ │ (可选)       │
         └────────┘ └──────────┘ └────────────┘ └──────────┘ └──────────────┘
                           │              │              │
                    ┌──────┴──────┐       ▼              ▼
                    ▼             ▼   ┌────────┐   ┌─────────┐
              ┌────────┐   ┌────────┐ │棘轮系统│   │下锚拉线  │
              │ 单臂   │   │ 双臂   │ │滑轮系统│   │拉线盘   │
              │(无横担)│   │(有横担)│ └────────┘   └─────────┘
              └────────┘   └────────┘
                               │
                          ┌────┴────┐
                          ▼         ▼
                     ┌────────┐ ┌────────┐
                     │ 平腕臂  │ │斜腕臂   │
                     │ 棒式绝缘│ │承力索座 │
                     │ 载流回路│ │定位器   │
                     └────────┘ └────────┘
```

### 2.1 约束装配模型（Constraint-Based Assembly）

接触网装配以**约束驱动**方式组织，每个组件定义若干**连接点（AttachPoint）**和**约束类型**，装配时通过约束求解定位，而非自由参数拼装。

#### 2.1.1 约束类型

| 约束类型 | 说明 | 示例 |
|----------|------|------|
| `Mate` | 面-面贴合 | 法兰盘底面贴合基础顶面 |
| `AxisAlign` | 轴线对齐 | 绝缘子轴线对齐连接座耳板孔轴线 |
| `Distance` | 距离约束 | 腕臂底座距轨面高度 |
| `Angle` | 角度约束 | 斜腕臂安装倾角 |
| `Insert` | 销/孔插入 | 螺栓穿过法兰孔，绝缘子球头插入腕臂底座球窝 |
| `Mirror` | 镜像复制 | 左右附加导线支架关于支柱中轴线对称 |

#### 2.1.2 可调参数（仅对外暴露设计控制量）

每个子系统仅保留少数设计输入参数，其余全部由约束链自动派生或查表确定：

| 子系统 | 可调参数 | 说明 |
|--------|----------|------|
| **支柱整体** | `Mileage`, `MastType`, `MastHeight`, `MastPurpose` | 柱位、型号、总高、用途 |
| **悬吊** | `CantileverType`, `HasCrossArm` | 单臂/双臂/有横担；其余导高/结构高度/拉出值由线路专业输入 |
| **腕臂** | `ArmDiameter` | 管径（型材规格查表）。长度由导高和拉出值约束求解 |
| **定位器** | `Stagger` | 拉出值（线路专业输入） |
| **补偿** | `CompType`, `RatedTension` | 棘轮/滑轮，设计张力。齿轮比/滑轮数为张力导出 |
| **坠砣** | `RatedTension` | 设计张力 → 自动确定坠砣数量和总重 |
| **拉线** | `HasGuyWire` | 有/无。角度/规格根据柱高和补偿张力计算 |
| **附加导线** | `WireCount`, `StaggerY[]` | 根数+每根Y偏移 |

> 其余参数（如螺栓孔距、伞裙数、孔径等）均预置于相应的 **标准件库/TB 规格表** 中，由型号关键字查表获得，不暴露在装配参数中。

#### 2.1.3 支柱整体装配（MastAssembly）— 对外唯一入口

**关键字**: `TYPE=OCS_MAST_ASSEMBLY`

| 可调参数 | 类型 | 说明 |
|----------|------|------|
| `Mileage` | string | 里程桩号 |
| `MastType` | int | 1-格构式钢柱, 2-混凝土柱 |
| `MastHeight` | mm | 柱全高 |
| `MastPurpose` | int | 1-中间柱, 2-锚柱, 3-转换柱 |
| `CantileverType` | int | 0-无, 1-单臂, 2-双臂 |
| `HasCrossArm` | bool | 双臂时是否有横担 |
| `ArmDiameter` | mm | 腕臂管外径 |
| `Stagger` | mm | 接触线拉出值 (Y方向偏移) |
| `CompType` | int | 0-无, 1-棘轮, 2-滑轮 |
| `RatedTension` | kN | 设计补偿张力 |
| `HasGuyWire` | bool | 是否设下锚拉线 |
| `AuxWires` | []WireConfig | 附加导线配置列表 |

**Go 结构体**: `MastAssemblyParams`

#### 2.1.4 装配约束链

```
MastAssembly
 ├─[AxisAlign: 柱中轴线Z]
 │  └─ 支柱（Mast）— 柱底原点为装配基准
 │
 ├─[Distance: 安装高度H]─[AxisAlign: 柱腹板XZ面]
 │  └─ 支柱连接座（MastBracket）— 上下两个
 │     ├─[Insert: 螺栓孔 ↔ 柱安装孔]
 │     └─[AxisAlign: 耳板孔轴线Y]
 │         └─ 棒式绝缘子
 │            └─[Insert: 法兰螺栓孔]
 │                └─ 腕臂底座
 │                   └─[AxisAlign: 腕臂管轴线]
 │                       ├─ 平腕臂（LevelArm）
 │                       │  ├─[Distance: 承力索座位置X]
 │                       │  │  └─ 承力索座（MWSaddle）
 │                       │  │     └─[Mate: 线槽 ↔ 承力索]
 │                       │  └─[AxisAlign: 斜腕臂上端点]
 │                       │      └─ 斜腕臂（SlantArm）上端
 │                       └─ 斜腕臂（SlantArm）下端
 │                          └─[AxisAlign: 下连接座轴线]
 │                              └─ 定位器（RegArm）
 │                                 └─[Distance: Stagger Y]
 │                                     └─ 接触线
 │
 ├─[Distance: 柱顶安装点Z]─[Angle: 补偿方向]
 │  └─ 补偿装置（补偿绳 + 坠砣杆 + 坠砣串）
 │
 ├─[Distance: 柱上部2/3高度]─[Angle: 45°±15°]
 │  └─ 下锚拉线（拉线 + 绝缘子 + 拉线基础）
 │
 └─[Distance: 柱顶/横担端部]─[Mirror: 关于柱中线]
     └─ 附加导线支架 + 绝缘子 + 导线
```

### 2.1.5 锚段生成器（Anchor Section Generator）

在逐柱 `MastAssembly` 之上，提供一个锚段级别的生成入口。输入道路中心线和锚段规格，自动计算各柱位坐标、展开所有 `MastAssemblyParams` 并生成完整锚段。

#### 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `Centerline` | GeoJSON LineString | 道路中心线（X-Y 坐标序列），作为线路定位基准 |
| `SpanCount` | int | 跨数：3 / 4 / 5 / 8 等 |
| `SpanLength` | float | 标准跨距 (mm)，一般 50000~65000 |
| `ContactHeight` | float | 导高 (mm)，默认 5300 |
| `SystemHeight` | float | 结构高度 (mm)，承力索与接触线垂直间距 |
| `StaggerTable` | []float | 各定位点拉出值 (mm)，之字形 ±200~±400，长度 = SpanCount+1 |
| `StartMileage` | float | 起始里程 (m) |
| `HasCompensator` | bool | 是否在两端设补偿装置 |
| `RailType` | string | 轨型，用于轨道同时生成 |

#### 生成逻辑

```
Centerline (GeoJSON LineString)
  │ 采样起止里程，按 SpanLength 分割
  ▼
各柱位里程 → 从 Centerline 投影得到柱位坐标 (X,Y,Z)
  │ Z 从 Centerline 或 DEM 插值取地面高程
  ▼
逐柱配置 MastAssemblyParams：
  ├─ 锚段两端 MastPurpose=锚柱, HasGuyWire=true, 补偿=有
  ├─ 中间柱 MastPurpose=中间柱, 补偿=无, 横担=按需
  └─ Stagger[i] 注入各柱位定位器拉出值
  ▼
逐柱调用 BuildMastAssembly(params) → 各支柱装配
  ▼
柱间连线索：
  ├─ 接触线：BezierCurve 沿各柱位的定位器线夹点顺序连接
  ├─ 承力索：同上，Z 偏移 +SystemHeight
  └─ 吊弦：接触线与承力索之间的垂直短线，间距 4~12m
  ▼
输出：完整锚段 → [Mast群] + [承力索] + [接触线] + [吊弦群] + [补偿装置]
```

> 不依赖点云时，道路中心线提供平纵断面；无点云时可用设计中心线（纸上定线）。各柱位 Z 坐标从中心线的高程字段取得（若无高程则假定为 0 平面）。

# 第二部分：接触网体系（OCS）

## 1. 接触线与承力索

### 1.1 接触线

**关键字**: `TYPE=OCS_CW`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 型号 | `TYPE` | - | 例：CTHA-120, CTS-150 | - |
| 截面积 | `SectionalArea` | mm² | - | >0 |
| 标称直径 | `Diameter` | mm | - | >0 |
| 额定张力 | `RatedTension` | kN | 展放张力 | 10~40 |
| 最大允许张力 | `MaxTension` | kN | - | - |
| 单位长度质量 | `WeightPerMeter` | kg/m | - | >0 |
| 载流量 | `CurrentCapacity` | A | - | - |
| 弹性模量 | `ElasticModulus` | N/mm² | - | - |
| 线膨胀系数 | `ExpansionCoeff` | 1/℃ | - | - |

**建模要点：**
- 通用模型：以锚段为单位，沿 X 轴方向
- 接触线坡度变化处采用分段直线/折线描述
- 拉出值通过 Y 方向偏移实现
- 坐标原点：锚段起点接触线高度位置
**几何构成：**
**几何构成：**
1. 截面：顶部夹持面（半圆 R=2~3mm + 直边），中部梯形过渡，底部圆弧 R=6~10mm，两侧沟槽（深 2mm，宽 3mm）
2. `BRepBuilderAPI_MakeWire` 闭合 + `BRepBuilderAPI_MakeFace` + `BRepOffsetAPI_MakePipeShell` 沿锚段中心线扫掠
3. 铜合金色 R=204/G=102/B=0，中部梯形过渡，底部接触面（圆弧 R=6~10mm）+ 两侧沟槽（深 2mm，宽 3mm）
2. 顶部夹持面光滑 R=3mm 圆弧，底部接触面 R=8mm 大圆弧
3. 沟槽尖角 R0.5mm 圆角，避免应力集中
4. 沿锚段中心线 `BRepOffsetAPI_MakePipeShell` 扫掠
5. 铜合金色：R=204/G=102/B=0，金属光泽，接触面呈磨亮光泽（略浅）
6. 接头处 `BRepAlgoAPI_Common` 斜切 45° 接缝，使用 `BRepBuilderAPI_MakeWire` + `BRepBuilderAPI_MakeFace` 构建 2D 草图
2. 扫掠：沿锚段中心线（X 方向）做 `BRepOffsetAPI_MakePipeShell`，可处理多段折线衔接
3. 截面沟槽位于底部，两侧为接触面，顶部为夹持面
4. 拉出值通过在中心线的 Y 方向偏移叠加正弦波曲线实现
5. 导线坡度在 Z 方向渐变

**Go 结构体**: `ContactWireParams`

### 1.2 承力索

**关键字**: `TYPE=OCS_MW`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 型号 | `TYPE` | - | 例：JTMH-95, TJ-150 | - |
| 截面积 | `SectionalArea` | mm² | - | >0 |
| 直径 | `Diameter` | mm | - | >0 |
| 额定张力 | `RatedTension` | kN | - | 15~30 |
| 单位长度质量 | `WeightPerMeter` | kg/m | - | >0 |
| 弹性模量 | `ElasticModulus` | N/mm² | - | - |
| 线膨胀系数 | `ExpansionCoeff` | 1/℃ | - | - |
| 结构高度 | `StructuralHeight` | mm | 接触线到承力索垂直距离 | - |

**建模要点：**
- 承力索与接触线共同组成链形悬挂
- 结构高度沿跨距变化
- 坐标原点：锚段起点接触线高度位置（Y=0, Z=结构高度）
**几何构成：**
1. 截面：圆形截面，使用 `gp_Circ` 创建圆，`BRepBuilderAPI_MakeEdge` + `BRepBuilderAPI_MakeWire`
2. 扫掠：沿锚段中心线 `BRepOffsetAPI_MakePipe`，弧垂曲线可用 `Geom_BezierCurve` 或样条线
3. 承力索在 Y 方向与接触线对齐，Z 方向偏移量为结构高度
4. 直径为导线外径，绞合纹理不在通用模型中体现

**Go 结构体**: `MessengerWireParams`

### 1.3 吊弦（Dropper Assembly）

由 **吊弦线** + **载流线夹** + **载流回路** 统一组成的完整吊弦装配。每根吊弦垂直连接承力索与接触线，导电型吊弦同时承担载流通路功能。

**关键字**: `TYPE=OCS_DROPPER`

#### 1.3.1 吊弦线参数

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-整体吊弦, 2-可调吊弦 | 1~2 |

#### 1.3.2 载流线夹参数

| 参数 | 关键字 | 单位 | 说明 | 约束 |

#### 1.3.3 载流回路参数

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 载流方式 | `JumperType` | - | 1-铜绞线, 2-铜带, 3-预成型软铜绞线 | 1~3 |
| 载流线截面积 | `JumperSection` | mm² | 载流回路等效截面 | ≥70 |
| 载流线数量 | `JumperCount` | 根 | 并联载流线根数 | 1~4 |
| 载流线材质 | `JumperMaterial` | - | 1-铜, 2-铜合金 | 1~2 |
| 跨接路径 | `JumperRoute` | - | 1-承力索间, 2-接触线间, 3-全导通 | 1~3 |

**建模要点：**
- 吊弦沿跨距以 `Spacing` 均布，长度由承力索与接触线的结构高度自动计算
- 每根吊弦 = 吊弦线 + 上端载流线夹 + 下端载流线夹 + 载流回路（导电型）
- 坐标原点：承力索与吊弦连接点
- 非导电型吊弦仅提供机械连接，不含载流回路

**几何构成（吊弦 = 吊弦线 + 载流线夹 + 载流回路）：**

**吊弦线：**
- `BRepBuilderAPI_MakeEdge` 从承力索底面到接触线顶面的垂直线段
- 长度 `Length` 随跨中至支柱位置变化（跨中最大，支柱点最小）
- `BRepOffsetAPI_MakePipe` 沿线段扫掠圆形截面，径 `WireDiameter/2`
- 可调吊弦在中间增加一个螺纹调节器（`MakeCylinder` 螺母+螺杆）

**载流线夹（上端/下端）：**
- 上端线夹：`MakeBox` 夹块 + 弧形槽 `Cut`（卡入承力索）+ 螺栓孔 `Cut`
- 下端线夹：`MakeBox` 夹块 + 弧形槽 `Cut`（卡入接触线）+ 螺栓孔 `Cut`
- 两线夹分别 `BRepAlgoAPI_Fuse` 于吊弦线两端

**载流回路（仅导电型）：**
- `Geom_BezierCurve` 沿吊弦路径 + 载流线夹外侧布设
- `BRepOffsetAPI_MakePipe` 扫掠载流线截面
- 多根并联时并行排列
- 与吊弦线合并为统一实体

**Go 结构体**: `DropperAssemblyParams` — 含吊弦线、载流线夹、载流回路的完整吊弦装配

## 2. 整体悬吊装置

腕臂底座、横担、腕臂管、承力索座、定位器、载流回路及线夹等集成为一个整体悬吊单元。每根支柱处安装一个悬吊单元，完成对接触线和承力索的支撑、定位和电气连通。

### 2.1 横担（Cross-arm）

**关键字**: `TYPE=OCS_CROSS_ARM`

固定于支柱顶部的水平钢架结构，由横梁（水平）和斜撑（竖直方向）两组钢架组成门型刚架。横担为腕臂提供安装基座，将接触网负载传递至支柱。适用于双叉臂（固定腕臂）形式的接触网悬挂。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-双叉臂固定横担, 2-三角撑横担, 3-桁架式横担 | 1~3 |
| 横梁长度 | `BeamLength` | mm | 水平横梁外缘全长 | >0 |
| 横梁截面高 | `BeamHeight` | mm | - | >0 |
| 横梁截面宽 | `BeamWidth` | mm | - | >0 |
| 横梁壁厚 | `BeamThickness` | mm | - | >0 |
| 斜撑长度 | `BraceLength` | mm | 竖直斜撑长度 | >0 |
| 斜撑截面 | `BraceSection` | mm | 斜撑截面规格 | - |
| 安装高度 | `MountHeight` | mm | 横担重心距轨面高度 | - |
| 螺栓孔间距 | `BoltSpacing` | mm | 与支柱连接螺栓孔 | - |
| 螺栓孔径 | `BoltDiameter` | mm | - | - |
| 螺栓数量 | `BoltCount` | 个 | - | ≥4 |
| 材质 | `Material` | - | Q235B, Q355B | - |
| 表面处理 | `SurfaceFinish` | - | 1-热镀锌, 2-涂装 | - |

**建模要点：**
- 横担为刚性钢架结构，由横梁（水平）和斜撑（竖向）两组钢架焊接或螺栓连接而成
- 横梁沿线路横向布置，斜撑连接横梁外端与支柱上部，形成三角形受力体系
- 横担上安装腕臂底座，承接腕臂系统
- 适用于双叉臂/固定腕臂形式的接触网悬挂
- 对于双线路腕臂，横担两侧对称悬挑
- 原点：横担与支柱连接面中心

**几何构成：**
1. 横梁主梁：`BRepPrimAPI_MakeBox` 矩形截面梁，四条竖棱 `BRepFilletAPI_MakeFillet` R3~R5 圆角
2. 斜撑杆：`BRepPrimAPI_MakeBox` 矩形截面 + `gp_Trsf` 旋转，两端 `BRepFilletAPI_MakeFillet` R4 圆角
3. 节点连接板：`BRepPrimAPI_MakeBox` 厚 12mm 三角形节点板，三边 R4 圆角
4. 横梁与斜撑合并 `BRepAlgoAPI_Fuse`，连接板与杆件 `Fuse`
5. 镀锌钢色 R=204/G=204/B=204
6. 原点：横担与支柱接触面中心，四条竖棱 `BRepFilletAPI_MakeFillet` 圆角 R3~R5，端部斜切角 15° 防应力集中
2. 斜撑杆：`BRepPrimAPI_MakeBox` + `gp_Trsf` 旋转，两端 `BRepFilletAPI_MakeFillet` 圆角，与横梁连接节点板 `BRepPrimAPI_MakeBox` 厚 12mm 三角形节点板，三边圆角
3. 螺栓连接：`BRepPrimAPI_MakeCylinder` 螺栓孔 `BRepPrimAPI_MakeCylinder` 阵列 `BRepAlgoAPI_Cut`
4. 焊缝：节点板与横梁/斜撑之间 `BRepPrimAPI_MakeCylinder` 连接线
5. 表面镀锌层：整体色 R=204/G=204/B=204，A=1.0，金属光泽
6. 分段标识：节段拼接处设 2mm 深刻线 `BRepAlgoAPI_Cut` 矩形槽，标示拼装位置
7. 原点，长 `BeamLength`，截面 `BeamWidth×BeamHeight`
2. 斜撑：`BRepPrimAPI_MakeBox` 斜撑杆，旋转至设计角度
3. `BRepAlgoAPI_Fuse` 合并为整体刚架
4. 连接板：`BRepPrimAPI_MakeBox` + 减螺栓孔
5. 安装法兰：`BRepPrimAPI_MakeBox` + 减孔
6. 以支柱轴线对称，Y 方向悬挑

**Go 结构体**: `CrossArmParams`

### 2.2 平腕臂（Level Cantilever）

水平放置的腕臂管，一端通过底座固定于横担，另一端悬挑。平腕臂上安装承力索座以支撑承力索。

**关键字**: `TYPE=OCS_CANT_LEVEL`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 长度 | `Length` | mm | 平腕臂总长 | >0 |
| 外径 | `OuterDiameter` | mm | 钢管外径 | >0 |
| 壁厚 | `WallThickness` | mm | 钢管壁厚 | >0 |
| 安装高度 | `MountHeight` | mm | 距轨面高度 | - |
| 水平仰角 | `RiseAngle` | ° | 水平管略向上倾斜角 | 0~5 |

**Go 结构体**: `LevelCantileverParams`
**几何构成：**
1. 主体：薄壁圆管，`BRepPrimAPI_MakeCylinder` 生成外圆柱，`BRepPrimAPI_MakeCylinder` 生成内圆柱，`BRepAlgoAPI_Cut` 得到管状
2. 管端斜切：`BRepAlgoAPI_Common` 与斜切平面求交，得到腕臂管端部45°斜切面
3. 两端焊接法兰盘或连接耳板：`BRepPrimAPI_MakeBox` 生成矩形板，布孔用 `BRepAlgoAPI_Cut` 切圆柱
4. 整体沿 X 轴水平放置，仰角通过旋转 `gp_Trsf` 施加
5. 原点：腕臂与底座连接孔中心

### 2.3 斜腕臂（Slanted Cantilever）

倾斜放置的腕臂管，下端通过底座固定于支柱，上端连接至平腕臂悬挑端。与平腕臂形成三角支撑结构。

**关键字**: `TYPE=OCS_CANT_SLANT`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 长度 | `Length` | mm | 斜腕臂总长 | >0 |
| 外径 | `OuterDiameter` | mm | 钢管外径 | >0 |
| 壁厚 | `WallThickness` | mm | 钢管壁厚 | >0 |
| 安装倾角 | `SlantAngle` | ° | 相对铅垂线的倾斜角度 | 30~60 |

**Go 结构体**: `SlantCantileverParams`
**几何构成：**
1. 主体：薄壁圆管，构造方式同平腕臂 `Cylinder - Cylinder`
2. 两端斜切：斜切平面法向量与管轴线成安装倾角，用 `BRepAlgoAPI_Common` 实现
3. 上下端焊接连接耳板：`BRepPrimAPI_MakeBox` + 布尔减螺栓孔
4. 安装时绕 Y 轴旋转 `SlantAngle`，使上端指向平腕臂外端
5. 原点：斜腕臂下端底座连接孔中心

### 2.4 弯臂（Curved Arm）

**关键字**: `TYPE=OCS_CURVED_ARM`

从支柱上方安装的弯曲悬臂钢管，整体呈弧形或 L 形，用于悬吊供电线、回流线、加强线等附加导线。弯臂根部固定在支柱顶部或横担端部，弯头下垂或弯曲延伸以悬挂导线。

| 参数 | 关键字 | 单位 | 说明 | 约束 |

| 竖直段长度 | `VerticalLength` | mm | 从安装点至弯折点垂直段长度 | >0 |
| 水平段长度 | `HorizontalLength` | mm | 弯折后水平悬挑长度 | >0 |
| 弯曲半径 | `BendRadius` | mm | 弯折处圆弧半径 | ≥150 |
| 弯曲角度 | `BendAngle` | ° | 弯折角度 | 0~180 |
| 管外径 | `OuterDiameter` | mm | 钢管外径 | >0 |
| 壁厚 | `WallThickness` | mm | 钢管壁厚 | >0 |
| 总长 | `TotalLength` | mm | 展开总长 | - |
| 安装法兰厚度 | `FlangeThickness` | mm | 柱顶法兰厚 | - |
| 法兰螺栓孔间距 | `BoltSpacing` | mm | - | - |
| 法兰螺栓孔径 | `BoltDiameter` | mm | - | - |
| 悬挂点数量 | `HangPointCount` | 个 | 可悬挂导线数量 | 1~4 |
| 悬挂点间距 | `HangPointSpacing` | mm | 多线悬挂间距 | - |
| 材质 | `Material` | - | 1-钢管, 2-铝合金管 | 1~2 |
| 表面处理 | `SurfaceFinish` | - | 1-热镀锌, 2-涂装 | - |

**建模要点：**
- 弯臂从支柱上方伸出，主体为弯曲钢管
- 弯头处通常设置导线悬挂点（悬垂线夹或耐张线夹）
- 多根附加导线可并排悬挂于弯臂水平段
- 弯臂通过法兰或插接方式固定于柱顶
- 对于承载较大张力的附加导线，可采用双弯臂结构
- 原点：弯臂安装法兰底面中心

**几何构成：**
1. 中心线：`Geom_TrimmedCurve` 由竖直段+圆弧段(`BendRadius`)+水平段组成 L 形
2. `BRepOffsetAPI_MakePipe` 沿中心线扫掠圆形截面
3. 壁厚：外管 `BRepAlgoAPI_Cut` 内管
4. 安装法兰：`BRepPrimAPI_MakeBox` 柱顶法兰
5. 悬挂点：水平段底部 U 型耳板

**Go 结构体**: `CurvedArmParams`

### 2.6 支柱连接座（Mast Mounting Bracket）

**关键字**: `TYPE=OCS_MAST_BRACKET`

固定于支柱上的金属连接件，用于安装棒式绝缘子和腕臂底座。在双叉臂系统中，通常设置上下两个连接座，分别对应平腕臂和斜腕臂的安装。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-单联座, 2-双联座, 3-可调式 | 1~3 |
| 安装孔间距 | `BoltSpacing` | mm | 与支柱连接的螺栓孔间距 | >0 |
| 安装孔径 | `BoltDiameter` | mm | - | - |
| 连接座高度 | `Height` | mm | 座体高度 | >0 |
| 连接座宽度 | `Width` | mm | 座体宽度 | >0 |
| 连接座厚度 | `Thickness` | mm | 钢板厚度 | ≥10 |
| 绝缘子安装孔间距 | `InsulatorBoltSpacing` | mm | 连接棒式绝缘子的孔距 | - |
| 绝缘子安装孔径 | `InsulatorBoltDiameter` | mm | - | - |
| 安装角度 | `MountAngle` | ° | 连接座倾斜角度 | 0~60 |

**建模要点：**
- 支柱连接座为焊接或铸造金属件，通过螺栓固定于工字带孔支柱腹板或钢柱法兰
- 双叉臂系统设置上下两个连接座：上连接座固定平腕臂棒式绝缘子，下连接座固定斜腕臂棒式绝缘子
- 连接座位置决定腕臂系统的安装高度和角度
- 原点：连接座与支柱接触面中心

**几何构成：**
1. 座体主体：`BRepPrimAPI_MakeBox` 矩形金属板，宽 `Width`×高 `Height`×厚 `Thickness`
2. 支柱安装螺栓孔：`BRepPrimAPI_MakeCylinder` × N，`BRepAlgoAPI_Cut` 阵列切除
3. 绝缘子安装耳板：座体外侧延伸出的两块平行耳板，`BRepPrimAPI_MakeBox` + 端部倒圆
4. 耳板孔：`BRepPrimAPI_MakeCylinder` 垂直穿过耳板，`BRepAlgoAPI_Cut`，`InsulatorBoltDiameter`×`InsulatorBoltSpacing`

**挖孔桩基础（FOUND_EXCAVATED_PILE）：**

| 所属绳 | `RopeType` | - | 1-横向承力索, 2-上部固定绳, 3-下部固定绳 |
| 悬挂线夹类型 | `ClampType` | - | 1-悬垂线夹, 2-固定线夹 |
| 绝缘子编号 | `InsulatorID` | - | 关联绝缘子配置编号 |

**建模要点：**
- 横向承力索为上凸弧线，跨中弧垂最大，两端固定在支柱顶部
- 上部固定绳水平布置，连接各悬挂点上部
- 下部固定绳水平布置，连接各悬挂点下部，承托接触悬挂
- 绝缘子串串接在横向承力索/固定绳与支柱连接点之间
- 悬挂线夹位于各悬挂点，将接触悬挂固定于软横跨

**几何构成（导线模型参照 GIM TransmissionLineParams）：**
1. **横向承力索**：`Geom_BezierCurve` 定义上凸弧线（两端高、跨中低），`BRepOffsetAPI_MakePipe` 或 `BRepOffsetAPI_MakePipeShell` 扫掠圆形截面（径 `CrossCatenaryDia/2`），弧垂 `CrossCatenarySag`
2. **上部固定绳**：`BRepBuilderAPI_MakeEdge` 水平直线从左支柱到右支柱，`MakePipe` 扫掠圆形截面
3. **下部固定绳**：同上，在 Z 方向低于上部固定绳（间距由接触悬挂高度决定）
4. **绝缘子串**：每个支柱连接点处 `BRepPrimAPI_MakeCylinder` + `BRepPrimAPI_MakeCone` 伞裙阵列（参照 2.5），串接在横向承力索/固定绳与支柱之间，沿线路方向排列
5. **悬挂线夹**：每个 `HangPoint` 处 `MakeBox` 夹块 + 弧形槽 `Cut` `（径对应接触悬挂），BRepAlgoAPI_Fuse` 于横向承力索/固定绳交汇点
6. 图中以虚线示意各悬挂点到接触悬挂的垂直吊线（不建实体）

**Go 结构体**: `HeadSpanParams`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|

- 硬横跨为门式刚架：横梁水平跨越，两端立柱垂直支撑
- 箱型截面由四块钢板焊接组成；H型截面可用 IShapedSteel 基本图元
- 桁架式由上/下弦杆 + 腹杆组成，见几何构成
- 横梁跨中设预拱度（一般为跨距的 1/500~1/1000）
- 横梁分段运输，现场拼装

**几何构成：**

**箱型/H型横梁（`BeamSectionType=1/2`）：**
1. 截面：`BRepBuilderAPI_MakeWire` 闭合箱型轮廓 + `BRepBuilderAPI_MakeFace`
2. 拉伸：`BRepPrimAPI_MakePrism` 沿 X 方向拉伸 `Span`
3. 预拱度：中心线采用 `Geom_BezierCurve` 微凸弧线，`BRepOffsetAPI_MakePipeShell` 沿弧线扫掠截面

**桁架式横梁（`BeamSectionType=3`）：**
1. 上弦杆：`BRepPrimAPI_MakeBox` 角钢/钢管截面，沿上弦折线路径 `BRepOffsetAPI_MakePipe`
2. 下弦杆：同上，沿下弦折线路径
3. 腹杆：上、下弦杆之间 Z 字形/W 形/K 形布置，`BRepPrimAPI_MakeBox` 截面 + `gp_Trsf` 旋转到各节间对角线位置
4. 节点板：`BRepPrimAPI_MakeBox` 节点板 + `BRepAlgoAPI_Fuse` 于各腹杆交汇处

**立柱（两侧）：**
1. 参照 3.1 钢支柱或 3.2 混凝土支柱构造
2. 柱顶设连接法兰，柱身 `MakeBox` 或格构式
3. 外倾 `MastLeanAngle` 通过 `gp_Trsf` 旋转

**连接节点：**
1. `BRepPrimAPI_MakeBox` 节点板 + 螺栓孔 `BRepPrimAPI_MakeCylinder` `Cut`
2. 法兰盘 `BRepPrimAPI_MakeBox` + 螺栓 `BRepPrimAPI_MakeCylinder`
3. 梁端与柱顶 `BRepAlgoAPI_Fuse` 合并为整体刚架

**Go 结构体**: `TransverseSpanParams`

### 6.3 吊柱（Transverse Span Hanger / Suspension Post）

吊柱是从硬横跨横梁下方垂直伸出的悬吊式短柱，用于在各股道位置安装腕臂系统。吊柱上端通过法兰或焊接固定于横梁，下端提供支柱连接座安装面。

**关键字**: `TYPE=OCS_HANGER_POST`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 截面形式 | `SectionType` | - | 1-圆管, 2-方管, 3-H型钢 | 1~3 |
| 吊柱长度 | `Length` | mm | 从横梁底面至腕臂安装点 | >0 |
| 截面外径/边长 | `SectionSize` | mm | 圆管外径或方管边长 | >0 |
| 壁厚 | `WallThickness` | mm | 管壁/板厚 | ≥4 |
| 上端法兰边长 | `TopFlangeSize` | mm | 与横梁连接法兰 | - |
| 上端法兰厚度 | `TopFlangeThick` | mm | - | - |
| 下端法兰边长 | `BottomFlangeSize` | mm | 腕臂底座安装法兰 | - |
| 下端法兰厚度 | `BottomFlangeThick` | mm | - | - |
| 法兰螺栓孔径 | `BoltDiameter` | mm | - | - |
| 法兰螺栓间距 | `BoltSpacing` | mm | - | - |
| 沿横梁位置 | `PositionOnBeam` | mm | 吊柱在横梁上的 X 坐标 | - |

**建模要点：**
- 吊柱沿横梁跨度方向等距布置，每根对应一条股道的接触悬挂
- 上端法兰通过螺栓连接于横梁底面节点板
- 下端法兰安装腕臂底座及后续悬吊系统
- 多根吊柱可在一条硬横跨上布置（2~8根，根据站场股道数）

**几何构成：**
1. 主体：`BRepPrimAPI_MakeCylinder` (圆管) 或 `BRepPrimAPI_MakeBox` (方管)，沿 Z 轴方向
2. 壁厚：外管减内管 `BRepAlgoAPI_Cut`，中空薄壁
3. 上端法兰：`BRepPrimAPI_MakeBox` 矩形法兰板 + 螺栓孔 `BRepAlgoAPI_Cut`
4. 下端法兰：同上，可略小于上端法兰
5. 加劲肋：上端法兰底面与管体之间焊接三角肋板 `BRepPrimAPI_MakePrism`

**Go 结构体**: `HangerPostParams`

### 6.4 梁顶门型架（Beam-top Portal Frame）

骑跨于硬横跨横梁上方的门型钢架，两侧立柱夹持横梁，顶部横杆悬挂附加导线（供电线、回流线、架空地线等）。适用于站场硬横跨梁顶的附加导线支撑，通常靠梁端或中部布置。

**建模要点：**
- 门型架由两根垂直立柱 + 一根顶部水平横杆组成门形框架

4. 悬挂耳板：顶部横杆上 `BRepPrimAPI_MakeBox` 小耳板 + 圆孔 `Cut`，等距排列
5. 加劲肋：立柱与底座板之间三角肋板，前后各一

### 6.5 悬索（Suspension Cable / Catenary）

悬索是软横跨和悬索式硬横跨的共用核心构件，为两端锚固、中间自由下垂的柔性索。采用悬链线/抛物线近似建模，沿跨度方向形成弧垂。

**关键字**: `TYPE=OCS_SUSPENSION_CABLE`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 起点 | `StartPoint` | Point3 | 左端锚固点 | - |
| 终点 | `EndPoint` | Point3 | 右端锚固点 | - |
| 索径 | `Diameter` | mm | 绳索直径 | >0 |
| 弧垂 | `Sag` | mm | 跨中最大弧垂（从两端连线至索最低点） | ≥0 |
| 索类型 | `CableType` | - | 1-承力索(上凸)，2-固定绳(水平)，3-悬吊索(下凸) | 1~3 |
| 附加张拉力 | `Tension` | kN | 施工张拉力（0=仅几何造型） | ≥0 |

**三种索型：**

| 类型 | 曲线形状 | 应用场景 |
|------|----------|---------|
| `承力索` (CableType=1) | 上凸弧线，两端高、跨中低 | 软横跨横向承力索、悬索式硬横跨主索 |
| `固定绳` (CableType=2) | 水平直线 | 软横跨上/下部固定绳 |
| `悬吊索` (CableType=3) | 下凸弧线，两端低、跨中高 | 悬索式硬横跨的垂直悬吊索 |

**几何构成：**
1. 中心线：`Geom_BezierCurve` 三点控制（两端+弧垂最低/高点），定义索的空间走向
2. 扫掠：`BRepOffsetAPI_MakePipeShell` 沿中心线扫掠圆形截面（径 `Diameter/2`）
3. 索两端为平面切割端面，不体现接头金具

**建模要点：**
- 悬索作为独立图元，可被软横跨和悬索式硬横跨调用
- 弧垂 `Sag` 控制跨中最低/最高点相对于两端连线的垂直偏移
- 承力索型弧垂向下（弧线低于连线），固定绳型弧垂为0，悬吊索型弧垂向上
- 不与绳索张力的物理计算耦合，仅为几何造型参数

**Go 结构体**: `SuspensionCableParams`

---

### 6.6 悬索式硬横跨（Suspension Hard Span）

由两根刚性端立柱 + 一根悬索(承力索型) + 若干垂直悬吊索 + 悬挂点线夹组成的门形悬索结构。主索跨中弧垂，悬吊索垂直下挂，用于站场小跨距的接触悬挂支撑。

**装配层级：**
```
左侧立柱（Mast）
 ├─ 悬索左锚固点
 │   └─ 悬索（SuspensionCable, CableType=1）
 │       └─ 悬吊索×N（SuspensionCable, CableType=3）
 │            └─ 悬挂线夹 → 腕臂系统
 │       └─ 悬吊索×N
 │            └─ 悬挂线夹 → 腕臂系统
右侧立柱（Mast）
 └─ 悬索右锚固点
```

**Go 结构体**: `SuspensionHardSpanParams`

---

### 6.7 定位索（Positioning Cable）

定位索是从硬横跨横梁或软横跨固定绳向下垂挂的竖直钢索，用于替代刚性吊柱连接腕臂底座。定位索上端固定于横梁/固定绳，下端提供连接板安装腕臂系统。与软横跨的固定绳共用相同的直线索生成逻辑。

**关键字**: `TYPE=OCS_POSITIONING_CABLE`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 索径 | `Diameter` | mm | 钢索直径 | >0 |
| 上端连接点 | `TopPoint` | Point3 | 固定于横梁/固定绳的锚点 | - |
| 下端连接点 | `BottomPoint` | Point3 | 连接腕臂底座的锚点 | - |
| 是否可调 | `Adjustable` | bool | 是否带调节螺杆（长度微调） | - |

**几何构成：**
1. 索体：从 `TopPoint` 到 `BottomPoint` 的直线段，`BRepPrimAPI_MakeCylinder` 或 `BRepOffsetAPI_MakePipe` 扫掠圆形截面
2. 调节螺杆（Adjustable=true）：索体中部增加一个 `BRepPrimAPI_MakeCylinder` 螺杆段+ `BRepPrimAPI_MakeCone` 螺母
3. 上端连接板：`BRepPrimAPI_MakeBox` + 螺栓孔 `Cut`
4. 下端连接板：同构造

**建模要点：**
- 定位索为竖直直线索，不设弧垂（区别于悬索）
- 可调型索体中部设螺纹调节器，用于微调长度
- 与软横跨的固定绳(`cableType=2`)共用几何生成逻辑
- 一根桁架硬横跨可设置多根定位索（每根对应一股道）

**Go 结构体**: `PositioningCableParams`




## 7. 张力补偿装置

锚段两端设置自动张力补偿装置，用于保持接触线和承力索的张力恒定。铁路接触网常见型式包括棘轮补偿装置和滑轮补偿装置。

### 7.1 棘轮补偿装置（Ratchet Compensator）

| 补偿行程 | `StrokeLength` | mm | 坠砣最大行程 | 1000~2000 |
| 传动比 | `TransmissionRatio` | - | 棘轮杠杆比 | 1:3 ~ 1:5 |
| 棘轮直径 | `WheelDiameter` | mm | 棘轮节圆直径 | >0 |
| 棘轮宽度 | `WheelWidth` | mm | - | >0 |
| 补偿绳规格 | `WireRopeSpec` | - | 钢丝绳直径 | - |
| 补偿绳长度 | `WireRopeLength` | mm | - | - |
| 坠砣数量 | `WeightCount` | 块 | 坠砣块数 | - |
| 坠砣单重 | `WeightPerBlock` | kg | 每块重量 | 25~50 |

| 坠砣杆直径 | `WeightRodDiameter` | mm | - | >0 |
| 安装柱号 | `MastNo` | - | 关联锚柱编号 | - |

| 防护罩 | `HasCover` | bool | 是否带防护罩 | - |

**几何构成：**
1. **棘轮主体**：`BRepPrimAPI_MakeCylinder` 大直径圆盘，径 `WheelDiameter`，厚 `WheelWidth`
2. **齿槽**：`BRepPrimAPI_MakeBox` 小凹槽沿圆周阵列，`BRepAlgoAPI_Cut`，齿数按直径比例 20~40 齿
3. **补偿绳槽**：`BRepAlgoAPI_Cut` 环形槽，槽宽对应绳径
4. **中心轴孔**：`BRepPrimAPI_MakeCylinder` 贯通，`BRepAlgoAPI_Cut`
5. **减重孔**：圆盘上均布减重孔，`BRepAlgoAPI_Cut` 沿圆周阵列
6. **制动棘爪**：`BRepPrimAPI_MakeBox` 棘爪块 + 楔形啮合端 `BRepAlgoAPI_Cut`
7. **安装支架**：`BRepPrimAPI_MakeBox` 支座板 + 加劲肋，固定于支柱
8. **防护罩**：`BRepPrimAPI_MakeBox` 半包围壳体，`BRepFilletAPI_MakeFillet` 边缘倒圆

**建模要点：**
- 棘轮本体为带有齿槽结构的圆盘，齿槽用于制动
- 补偿绳从棘轮两侧引出，一侧连接绝缘子串（导线端），一侧连接坠砣
- 坠砣串沿坠砣杆垂直排列，可在一定范围内上下滑动
- 制动棘爪在断线时卡住棘轮防止坠砣坠落
- 防护罩为半包围金属壳体
- 原点：棘轮中心安装轴

**组件结构：**
```
棘轮补偿装置
 ├─ 棘轮本体（RatchetWheel）— 大直径齿槽圆盘
 ├─ 补偿绳（CompensatorRope）— 钢丝绳，走两轮
 │   ├─ 导线端 → 绝缘子串 → 下锚金具 → 接触线/承力索
 │   └─ 坠砣端 → 坠砣杆 → 坠砣串
 ├─ 制动棘爪（BrakePawl）
 ├─ 防护罩（ProtectiveCover）
 ├─ 坠砣杆（WeightRod）
 └─ 坠砣串（WeightStack）— N 块×单重
```

**Go 结构体**: `RatchetCompensatorParams`

### 7.2 滑轮补偿装置（Pulley Compensator）

**关键字**: `TYPE=OCS_PULLEY_COMP`

滑轮补偿装置通过动滑轮组实现张力补偿，普速和客货共线铁路常用。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 型号 | `Type` | - | 例：HLB-1, HLB-2 | - |
| 补偿方式 | `CompMethod` | - | 1-单滑轮组, 2-双滑轮组 | 1~2 |
| 额定张力 | `RatedTension` | kN | 设计补偿张力 | 10~30 |
| 补偿行程 | `StrokeLength` | mm | 坠砣最大行程 | 800~1500 |
| 传动比 | `TransmissionRatio` | - | 动滑轮倍数 | 1:2 ~ 1:4 |
| 滑轮直径 | `PulleyDiameter` | mm | 滑轮节圆直径 | >0 |
| 滑轮槽宽 | `GrooveWidth` | mm | 绳槽宽度 | - |
| 轮数 | `PulleyCount` | 个 | 定/动滑轮个数 | - |
| 补偿绳规格 | `WireRopeSpec` | - | 钢丝绳直径 | - |
| 补偿绳长度 | `WireRopeLength` | mm | - | - |
| 坠砣数量 | `WeightCount` | 块 | 坠砣块数 | - |
| 坠砣单重 | `WeightPerBlock` | kg | 每块重量 | 25~50 |
| 坠砣总重 | `TotalWeight` | kg | - | - |
| 坠砣杆直径 | `WeightRodDiameter` | mm | - | >0 |
| 转向轮 | `HasDeflectorPulley` | bool | 是否带转向轮 | - |
| 限制架 | `HasLimitFrame` | bool | 是否带坠砣限制架 | - |
| 安装柱号 | `MastNo` | - | 关联锚柱编号 | - |
| 补偿方向 | `CompDirection` | - | 1-大里程, 2-小里程 | 1~2 |

**几何构成：**
1. 定滑轮：`BRepPrimAPI_MakeCylinder` 盘体 + `BRepAlgoAPI_Cut` 环形绳槽，槽底半圆 R=绳径+1mm
2. 动滑轮：同构造，`BRepAlgoAPI_Cut` 减重孔 4 个
3. 中心轴孔 `BRepPrimAPI_MakeCylinder` 贯通
4. 补偿绳、转向轮、限制架、安装支架等见原步骤
5. 铸造色 R=130/G=130/B=130 + `BRepAlgoAPI_Cut` 环形绳槽，槽底半圆 R=绳径+1mm，槽边 `BRepFilletAPI_MakeFillet` R1，中心轴孔+滚动轴承内圈可见
2. **动滑轮**：同构造，质量轻于定滑轮（`BRepAlgoAPI_Cut` 减重孔 4 个）
3. **轴端挡圈**：`BRepPrimAPI_MakeBox` 环形板 + 定位螺栓
4. **轴承密封盖**：`BRepPrimAPI_MakeCylinder` 薄端盖，印有型号标记
5. **滑轮铸造**：色 R=130/G=130/B=130 球墨铸铁
6. 其余见原几何构成步骤 4-7
，槽宽 `GrooveWidth`；中心轴孔 `BRepAlgoAPI_Cut`
2. **动滑轮**：同定滑轮构造，位置随坠砣升降沿 Z 平移（`gp_Trsf` 设置 `StrokeLength` 范围内）
3. **滑轮组支架**：`BRepPrimAPI_MakeBox` 座体 + 销轴孔 `Cut`
4. **补偿绳**：`Geom_BezierCurve` 定滑轮与动滑轮之间的穿绕路径，`BRepOffsetAPI_MakePipe` 沿路径扫掠圆形截面（径 `WireRopeSpec/2`），穿绕次数 = `TransmissionRatio × 2`
5. **转向轮**（`HasDeflectorPulley`）：`BRepPrimAPI_MakeCylinder` 小滑轮 + 支架 `MakeBox`，布置于补偿绳转折处
6. **限制架**（`HasLimitFrame`）：`BRepPrimAPI_MakeBox` 矩形框架 + 开槽 `Cut`，包围坠砣串，限制横向摆动
7. **安装支架**：`BRepPrimAPI_MakeBox` 连接板 + 加劲肋 `BRepAlgoAPI_Fuse`，固定于支柱

**建模要点：**
- 滑轮组由定滑轮（固定于支柱）和动滑轮（随坠砣升降）组成
- 补偿绳穿绕方式由传动比决定
- 坠砣限制架防止坠砣横向摆动
- 转向轮用于改变补偿绳方向（空间受限时）
- 原点：定滑轮轴心

**组件结构：**
```
滑轮补偿装置
 ├─ 定滑轮组（FixedPulleyArray）— 固定于支柱上
 ├─ 动滑轮组（MovablePulleyArray）— 随坠砣移动
 ├─ 补偿绳（CompensatorRope）
 ├─ 转向轮（DeflectorPulley）
 ├─ 限制架（LimitFrame）
 ├─ 坠砣杆（WeightRod）
 └─ 坠砣串（WeightStack）
```

**Go 结构体**: `PulleyCompensatorParams`

**楔形线夹（Type=3）：**

，长 `Length`，直径 `Spec`
2. 杵头（一端）：`BRepPrimAPI_MakeSphere` 球头 + `BRepAlgoAPI_Fuse` 焊接于杆端

**装配层级（棘轮式）：**

**关键字**: `TYPE=OCS_AUX_BRACKET`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|
| 类型 | `Type` | - | 1-横担式, 2-壁挂式, 3-双支柱式 |
| 安装高度 | `MountHeight` | mm | 距轨面 |
| 悬挑长度 | `OverhangLength` | mm | 从支柱中心线伸出距离 |

| 固定螺栓间距 | `BoltSpacing` | mm | - |
| 固定螺栓直径 | `BoltDiameter` | mm | - |

**建模要点：**
- 横担式：水平角钢/槽钢从支柱侧面悬挑，用于架空悬挂附加导线
- 壁挂式：平板直接固定于支柱壁面，导线沿支柱敷设
- 双支柱式：跨越两组支柱间悬挂

**几何构成（按类型分述）：**

**横担式（Type=1）：**
1. 主梁：`BRepPrimAPI_MakeBox` 角钢截面（`AngleSpec`），长 `OverhangLength`，沿 Y 方向水平悬挑
2. 斜撑（可选）：`BRepPrimAPI_MakeBox` 斜撑杆，从主梁外端斜向下连接支柱，`gp_Trsf` 旋转至设计角度
3. 支柱连接板：`BRepPrimAPI_MakeBox` 矩形连接板 + 螺栓孔 `BRepPrimAPI_MakeCylinder` `Cut`（`BoltSpacing`×`BoltDiameter`）
4. 挂线点：主梁外端 `BRepPrimAPI_MakeBox` 小耳板 + 圆孔 `Cut`，用于连接绝缘子
5. `BRepAlgoAPI_Fuse` 合并主梁 + 斜撑 + 连接板

**壁挂式（Type=2）：**
1. 壁板：`BRepPrimAPI_MakeBox` 矩形平板，长 `BracketLength`×宽 `BracketWidth`，贴合支柱壁面安装
2. 安装螺栓孔：`BRepPrimAPI_MakeCylinder` × 4 角部孔，`BRepAlgoAPI_Cut`
3. 挂线耳板：壁板外侧焊接 `BRepPrimAPI_MakeBox` 耳板 + 圆孔 `Cut`

**双支柱式（Type=3）：**
1. 横梁：`BRepPrimAPI_MakeBox` 在两个支柱之间水平跨越，长 = 支柱间距
2. 两端连接座：`BRepPrimAPI_MakeBox` 连接板 + 螺栓孔 `Cut`，固定于两侧支柱
3. 挂线点：沿横梁按 `BracketLength` 间距均布

**Go 结构体**: `AuxBracketParams`

# 第三部分：轨道体系（点/线驱动的参数化建模）

## 1. 总则

### 1.1 设计理念

轨道系统采用**点/线驱动的参数化建模**（Point/Line-Driven Parametric Modeling）方式。每个轨道元素由三维空间中的几何基元独立描述，基元之间不存在隐含的中心线依赖关系。

| 基元类型 | 几何描述 | 轨道元素 |
|----------|----------|----------|
| 曲线 Curve | 独立路径（LINE/ARC/BEZIER） | 钢轨、翼轨、护轨 |
| 直线 Line | 有向线段 | 枕木、岔枕 |
| 点 Point | 三维坐标 | 扣件、减速顶、附属设施 |
| 集合 Collection | 基元组合+派生逻辑 | 道床(由枕木线派生)、道岔(元素集合)、伸缩调节器 |

### 1.2 几何基元类型

| 基元 | 关键字 | 输入 | 说明 |
|------|--------|------|------|
| 直线 | `LINE` | `起点, 终点` | 两点间直线段 |
| 圆弧 | `ARC` | `起点, 终点, 半径, 方向` | 圆弧段，含左偏/右偏标识 |
| 贝塞尔曲线 | `BEZIER` | `控制点[]` | 三次或更高次贝塞尔曲线 |
| 直线段 | `SEGMENT` | `起点, 终点` | 有方向、有长度的线段 |
| 点 | `POINT` | `x, y, z` | 三维空间坐标点 |

### 1.3 坐标系

同第一部分 1.2 轨道坐标系：Z 轴向上，X 轴沿线路大里程方向，Y 轴垂直于线路。

---

## 2. 曲线基元（Curve）

曲线基元是所有"轨"类元素（钢轨、翼轨、护轨）的共享几何基础。

### 2.1 空间曲线参数

| 参数 | 关键字 | 类型 | 说明 |
|------|--------|------|------|

### 2.3 端部处理（End Treatment）

曲线元素的任一端可独立定义端部处理方式。

**关键字**: `TYPE=TRACK_END`

| 参数 | 关键字 | 单位 | 说明 | 默认值 |
|------|--------|------|------|--------|
| 端部位置 | `EndPosition` | - | `START` / `END` | - |
| 处理类型 | `Treatment` | - | `PLANE`(平面切割) / `SWITCH`(尖轨) / `SCARF`(斜切) / `BELL`(喇叭口) | `PLANE` |
| 尖轨尖端宽度 | `ToeWidth` | mm | 尖端截面宽（SWITCH 用，趋近0） | 2 |
| 尖轨跟端宽度 | `HeelWidth` | mm | 跟端全剖面宽度 | 全宽 |
| 尖轨全长 | `SwitchLength` | mm | 尖轨段长度 | - |
| 尖轨刨削起点 | `PlanedStart` | mm | 从端部起刨削起始位置 | 0 |
| 尖轨类型 | `SwitchType` | - | 1-直线尖轨, 2-曲线尖轨 | 1 |
| 降值量 | `DropValue` | mm | 尖端降低值 | - |
| 斜切角 | `ScarfAngle` | deg | 斜切角度（SCARF 用） | 45 |
| 喇叭口长度 | `BellLength` | mm | 喇叭口段长度（BELL 用） | 500 |

> 每条曲线两端独立配置：`[START, END]`。约束组合：
> - `[PLANE, PLANE]`：普通轨，两端平切
> - `[SWITCH, PLANE]`：单尖轨，起点为尖轨
> - `[PLANE, SWITCH]`：单尖轨，终点为尖轨
> - `[SWITCH, SWITCH]`：双尖轨，两端均为尖轨
> - `[BELL, PLANE]`：一端喇叭口，一端平切（护轨用）

**几何构成（SWITCH 端）：** `BRepOffsetAPI_ThruSections` 从 `ToeWidth`×全高 变截面放样至全剖面。

## 6. 复合结构

复合结构由多个基元组合 + 派生逻辑生成。

### 6.1 道床（Ballast）

由枕木线集合驱动生成，非独立建模。

**关键字**: `TYPE=TRACK_BALLAST`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|
| 驱动力 | `Driver` | - | 由 `SleeperLines`（[]LineElementParams）派生 |
| 道床顶宽 | `TopWidth` | mm | 路肩宽度 |
| 道床边坡 | `SideSlope` | - | 1:1.5 ~ 1:1.75 |
| 道床厚度 | `Thickness` | mm | 轨枕底面以下 |
| 截面类型 | `SectionType` | - | 1-路基梯形, 2-桥梁梯形, 3-隧道矩形 |

**派生逻辑：**
```
Sleepers ([]LineElementParams)
  → 计算枕木覆盖范围 (bounding box)
  → 取中轴线作为道床中心线
  → 沿中轴线按梯形/矩形截面扫掠
  → 输出 Ballast
```

**Go 结构体**: `TrackBallastParams`

### 6.2 道岔（Turnout）


道岔由独立定义的钢轨、翼轨、护轨、岔枕、扣件按坐标对齐组装，无中心线自动检测。

**关键字**: `TYPE=TRACK_TURNOUT`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|
| 道岔号数 | `TurnoutNo` | - | 9号, 12号, 18号, 42号 |
| 类型 | `Type` | - | 1-单开, 2-对称, 3-交叉渡线, 4-复式交分 |
| 开向 | `Hand` | - | 1-左开, 2-右开 |
| 辙叉角 | `FrogAngle` | deg | alpha = arctan(1/N) |
| 轨距 | `Gauge` | mm | 1435 |

#### 6.2.1 构成元素

| 元素 | 基元类型 | 实例化参数 | 数量 |
|------|----------|-----------|------|
| 直基本轨 | `CurveElement` | Curve=LINE, Profile=RAIL, End=[PLANE,PLANE] | 1 |
| 曲基本轨 | `CurveElement` | Curve=ARC/BEZIER, Profile=RAIL, End=[PLANE,PLANE] | 1 |
| 直尖轨 | `CurveElement` | Curve=LINE, Profile=RAIL, End=[SWITCH,PLANE] | 1 |
| 曲尖轨 | `CurveElement` | Curve=ARC/BEZIER, Profile=RAIL, End=[SWITCH,PLANE] | 1 |
| 翼轨 | `CurveElement` | Curve=LINE, Profile=CHANNEL/RAIL | 2 |
| 护轨 | `CurveElement` | Curve=LINE, Profile=CHANNEL, End=[BELL,PLANE] | 2 |
| 岔枕 | `LineElement` | `LineElementParams` 长度沿位置渐变 | N |
| 扣件 | `PointElement` | `PointElementParams` | M |

#### 6.2.2 单开道岔元素组合

```
左开道岔（岔心为原点，直股沿 X 正向）：
 1. 直基本轨: Curve=LINE(-L1,+L2),        End=[PLANE,PLANE]
 2. 曲基本轨: Curve=ARC(-L1,R,right),     End=[PLANE,PLANE]
 3. 直尖轨:   Curve=LINE(-SwL,0),         End=[SWITCH,PLANE]
 4. 曲尖轨:   Curve=ARC(-SwL,R,right),    End=[SWITCH,PLANE]
 5. 翼轨 L:   Curve=LINE(-W1,+W2),        Profile=CHANNEL
 6. 翼轨 R:   Curve=LINE(-W1,+W2),        Profile=CHANNEL
 7-N. 岔枕:   Line(start[i], end[i]),     Length 随位置变长
 N+1-M. 扣件: Point(pos[j]), Side=BOTH
```

#### 6.2.3 辙叉

辙叉由独立元素在岔心处对齐形成，非独立建模：

| 组件 | 来源 | 说明 |
|------|------|------|
| 心轨 | 两股钢轨端部 `End=[SWITCH,...]` | 直股+侧股在岔心处汇聚，尖端约 2mm |
| 翼轨 | `TrackWingRailParams` × 2 | 心轨外侧独立曲线 |
| 护轨 | `TrackGuardRailParams` × 2 | 对侧短轨段，`End=[BELL,PLANE]` |

#### 6.2.4 道岔总装参数

```go
type TurnoutAssembly struct {
    TurnoutNo      int                    // 道岔号数
    Hand           int                    // 开向
    FrogAngle      float64                // 辙叉角（派生）
    Gauge          float64                // 轨距
    Rails          []CurveElementParams   // 直基本轨、曲基本轨、直尖轨、曲尖轨
    WingRails      []CurveElementParams   // 翼轨 ×2
    GuardRails     []CurveElementParams   // 护轨 ×2
    Sleepers       []LineElementParams    // 岔枕 ×N
    Fasteners      []PointElementParams   // 扣件 ×M
}
```

**生成流程：**
1. 逐 CurveElement: `MakePipeShell(Profile, Curve)` + 端部处理
2. 逐 LineElement: `MakeBox(SleeperSection, Line)`
3. 逐 PointElement: `MakeBox(FastenerPart, Position)`
4. `BRepAlgoAPI_Fuse` 合并为整体

**Go 结构体**: `TurnoutAssemblyParams`

### 6.3 钢轨伸缩调节器（Expansion Joint）

由两条 CurveElement 组合。

**关键字**: `TYPE=TRACK_EXP_JOINT`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|
| 基本轨 | `StockRail` | CurveElementParams | Curve=LINE, End=[PLANE,PLANE] |
| 尖轨 | `SwitchRail` | CurveElementParams | Curve=LINE, End=[SWITCH,PLANE] |
| 伸缩量 | `ExpansionCapacity` | mm | ±200~±500 |
| 轨距 | `Gauge` | mm | 1435 |

**生成逻辑：**
1. 基本轨沿直线扫掠
2. 尖轨变截面扫掠，尖端→跟端
3. 基本轨与尖轨贴合面滑动结构
4. 限位装置于扣件点位
5. 伸缩量通过尖轨沿基本轨的 X 向位移模拟

**Go 结构体**: `ExpansionJointParams`

## 8. 参数体系总览

### 8.1 几何基元层级

```
GeometricPrimitive
 ├── CurvePrimitive          LINE | ARC | BEZIER
 │    ├── + Profile           RAIL | CHANNEL | PLATE

 │    └── = CurveElement      钢轨 / 翼轨 / 护轨

 │         = LineElement     枕木 / 岔枕
 │
 └── PointPrimitive          (x,y,z) 坐标点
      └── + Rotation+Side
           = PointElement    扣件 / 减速顶 / 附属
```
