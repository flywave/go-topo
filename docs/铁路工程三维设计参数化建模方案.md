# 第一部分：通用规范

## 1. 坐标系与单位

| 项目 | 规范要求 |
|------|----------|
| 坐标系 | **右手空间直角坐标系（Right-hand Cartesian）** |
| 模型比例 | **1:1** |
| 长度单位 | **毫米（mm）** |
| 地理坐标系 | **CGCS2000（2000国家大地坐标系）** |
| 高程基准 | **1985国家高程基准** |
| 坐标轴（通用） | **Z 轴向上，X 轴指向线路大里程方向，Y 轴垂直于线路** |
| 角度单位 | **度（decimal degrees）** |

### 1.1 接触网坐标系

| 项目 | 约定 |
|------|------|
| 原点 | 接触网支柱基础顶面中心 / 线路中心线轨面标高 |
| X 轴 | 沿线路方向（大里程为正） |
| Y 轴 | 垂直线路方向（面向大里程，左侧为正） |
| Z 轴 | 垂直向上 |

### 1.2 轨道坐标系

| 项目 | 约定 |
|------|------|
| 原点 | 线路中心线轨面高程点（各里程桩号） |
| X 轴 | 沿线路方向（大里程为正） |
| Y 轴 | 垂直线路方向（面向大里程，左侧为正） |
| Z 轴 | 垂直向上 |

## 2. 体系架构

接触网参数化建模以 **支柱** 为装配主体，通过配置参数决定挂载的子系统和协同样式，对外只暴露一个入口——**支柱整体装配**。

```
                    ┌──────────────────────────────────────┐
                    │        对外唯一入口                   │
                    │      MastAssembly(params)             │
                    │  「以支柱为主体，配置各子系统」         │
                    └──────┬───────────────────────────┬───┘
                           │ 根据配置参数派生              │
              ┌────────────┼──────────────┬──────────────┼──────────────┐
              ▼            ▼              ▼              ▼              ▼
         ┌────────┐ ┌──────────┐ ┌────────────┐ ┌──────────┐ ┌──────────────┐
         │ 支柱本体 │ │ 悬吊系统 │ │ 补偿系统   │ │ 拉线系统 │ │ 附加导线系统 │
         │ (必选)  │ │ (单/双臂)│ │ (可选)     │ │ (可选)   │ │ (可选)       │
         └────────┘ └──────────┘ └────────────┘ └──────────┘ └──────────────┘
                           │              │              │
                    ┌──────┴──────┐       ▼              ▼
                    ▼             ▼   ┌────────┐   ┌─────────┐
              ┌────────┐   ┌────────┐ │棘轮系统│   │下锚拉线  │
              │ 单臂   │   │ 双臂   │ │滑轮系统│   │拉线盘   │
              │(无横担)│   │(有横担)│ └────────┘   └─────────┘
              └────────┘   └────────┘
                               │
                          ┌────┴────┐
                          ▼         ▼
                     ┌────────┐ ┌────────┐
                     │ 平腕臂  │ │斜腕臂   │
                     │ 棒式绝缘│ │承力索座 │
                     │ 载流回路│ │定位器   │
                     └────────┘ └────────┘
```

### 2.1 约束装配模型（Constraint-Based Assembly）

接触网装配以**约束驱动**方式组织，每个组件定义若干**连接点（AttachPoint）**和**约束类型**，装配时通过约束求解定位，而非自由参数拼装。

#### 2.1.1 约束类型

| 约束类型 | 说明 | 示例 |
|----------|------|------|
| `Mate` | 面-面贴合 | 法兰盘底面贴合基础顶面 |
| `AxisAlign` | 轴线对齐 | 绝缘子轴线对齐连接座耳板孔轴线 |
| `Distance` | 距离约束 | 腕臂底座距轨面高度 |
| `Angle` | 角度约束 | 斜腕臂安装倾角 |
| `Insert` | 销/孔插入 | 螺栓穿过法兰孔，绝缘子球头插入腕臂底座球窝 |
| `Mirror` | 镜像复制 | 左右附加导线支架关于支柱中轴线对称 |

#### 2.1.2 可调参数（仅对外暴露设计控制量）

每个子系统仅保留少数设计输入参数，其余全部由约束链自动派生或查表确定：

| 子系统 | 可调参数 | 说明 |
|--------|----------|------|
| **支柱整体** | `Mileage`, `MastType`, `MastHeight`, `MastPurpose` | 柱位、型号、总高、用途 |
| **悬吊** | `CantileverType`, `HasCrossArm` | 单臂/双臂/有横担；其余导高/结构高度/拉出值由线路专业输入 |
| **腕臂** | `ArmDiameter` | 管径（型材规格查表）。长度由导高和拉出值约束求解 |
| **定位器** | `Stagger` | 拉出值（线路专业输入） |
| **补偿** | `CompType`, `RatedTension` | 棘轮/滑轮，设计张力。齿轮比/滑轮数为张力导出 |
| **坠砣** | `RatedTension` | 设计张力 → 自动确定坠砣数量和总重 |
| **拉线** | `HasGuyWire` | 有/无。角度/规格根据柱高和补偿张力计算 |
| **附加导线** | `WireCount`, `StaggerY[]` | 根数+每根Y偏移 |

> 其余参数（如螺栓孔距、伞裙数、孔径等）均预置于相应的 **标准件库/TB 规格表** 中，由型号关键字查表获得，不暴露在装配参数中。

#### 2.1.3 支柱整体装配（MastAssembly）— 对外唯一入口

**关键字**: `TYPE=OCS_MAST_ASSEMBLY`

| 可调参数 | 类型 | 说明 |
|----------|------|------|
| `Mileage` | string | 里程桩号 |
| `MastType` | int | 1-格构式钢柱, 2-混凝土柱 |
| `MastHeight` | mm | 柱全高 |
| `MastPurpose` | int | 1-中间柱, 2-锚柱, 3-转换柱 |
| `CantileverType` | int | 0-无, 1-单臂, 2-双臂 |
| `HasCrossArm` | bool | 双臂时是否有横担 |
| `ArmDiameter` | mm | 腕臂管外径 |
| `Stagger` | mm | 接触线拉出值 (Y方向偏移) |
| `CompType` | int | 0-无, 1-棘轮, 2-滑轮 |
| `RatedTension` | kN | 设计补偿张力 |
| `HasGuyWire` | bool | 是否设下锚拉线 |
| `AuxWires` | []WireConfig | 附加导线配置列表 |

**Go 结构体**: `MastAssemblyParams`

#### 2.1.4 装配约束链

```
MastAssembly
 ├─[AxisAlign: 柱中轴线Z]
 │  └─ 支柱（Mast）— 柱底原点为装配基准
 │
 ├─[Distance: 安装高度H]─[AxisAlign: 柱腹板XZ面]
 │  └─ 支柱连接座（MastBracket）— 上下两个
 │     ├─[Insert: 螺栓孔 ↔ 柱安装孔]
 │     └─[AxisAlign: 耳板孔轴线Y]
 │         └─ 棒式绝缘子
 │            └─[Insert: 法兰螺栓孔]
 │                └─ 腕臂底座
 │                   └─[AxisAlign: 腕臂管轴线]
 │                       ├─ 平腕臂（LevelArm）
 │                       │  ├─[Distance: 承力索座位置X]
 │                       │  │  └─ 承力索座（MWSaddle）
 │                       │  │     └─[Mate: 线槽 ↔ 承力索]
 │                       │  └─[AxisAlign: 斜腕臂上端点]
 │                       │      └─ 斜腕臂（SlantArm）上端
 │                       └─ 斜腕臂（SlantArm）下端
 │                          └─[AxisAlign: 下连接座轴线]
 │                              └─ 定位器（RegArm）
 │                                 └─[Distance: Stagger Y]
 │                                     └─ 接触线
 │
 ├─[Distance: 柱顶安装点Z]─[Angle: 补偿方向]
 │  └─ 补偿装置（补偿绳 + 坠砣杆 + 坠砣串）
 │
 ├─[Distance: 柱上部2/3高度]─[Angle: 45°±15°]
 │  └─ 下锚拉线（拉线 + 绝缘子 + 拉线基础）
 │
 └─[Distance: 柱顶/横担端部]─[Mirror: 关于柱中线]
     └─ 附加导线支架 + 绝缘子 + 导线
```

> **约束求解逻辑**：给定 `MastHeight`、`MastPurpose`、`Stagger`、`CantileverType` 后，内部约束求解器按顺序确定各连接点在世界空间的位置和姿态，最终逐级实例化组件到对应位置，必要时进行 `BRepAlgoAPI_Fuse` 合并为一个装配体。

> **与点云数据的配合**：同一线路的不同锚段、不同柱位，各自传入独立的 `MastAssemblyParams`（柱高/导高/拉出值/有无补偿等均可逐柱不同），参数值从点云实测数据提取，从而实现整条接触网按实际外观逐柱还原。

### 2.4 轨道系统渲染优化

**约束：** 平直轨道段采用 **生成一段 + GPU Instancing 渲染** 模式，以大幅度减少几何数据量和 Draw Call 次数。

#### 2.4.1 实例化分段策略

| 区段类型 | 段长 | 实例化方式 | 说明 |
|----------|------|-----------|------|
| 平直线路 | 标准轨长 25m 或 100m | **单段生成，全线 Instancing** | 钢轨、扣件、轨枕的 X 向位置通过 Instance 变换矩阵传入 |
| 等半径圆曲线 | 按弧长 10~25m | **一个曲线段 + 旋转 Instancing** | 沿圆心角按固定步长旋转复制，每段轨枕间距对应 |
| 缓和曲线 | 每 5~10m 分段 | **分段生成，局部 Instancing** | 曲率渐变的短段序列，段内重复结构用实例化 |
| 道岔区 | 全岔一体的特殊段 | **不实例化** | 变截面尖轨、变长岔枕、非对称几何，无法复用 |

#### 2.4.2 实例化层级

```
轨道线路（全线）
 ├─ 基准段几何（SegmentGeometry）
 │   ├─ 钢轨截面 × 2（左右股）
 │   ├─ 扣件 × N（轨枕间距排列）
 │   └─ 轨枕 × N
 │
 └─ Instance 列表（TransformMatrix[]）
     ├─ Instance 0: X=0mm
     ├─ Instance 1: X=25000mm
     ├─ Instance 2: X=50000mm
     ├─ ...
     └─ Instance N: X=全线铺轨长度
```

#### 2.4.3 约束规则

| 规则 | 说明 |
|------|------|
| 基准段必须为 **纯平直** 或 **等截面** 几何，不含变截面 | 确保 Instancing 正确性 |
| 扣件和轨枕间距在基准段内固定（如 600mm） | 间距无需存储，由 Instance 计数推导 |
| 左右股钢轨的 Y 偏移（±751.5mm）在 Instance 变换矩阵中携带 | 每条 Instance 可独立设置变换 |
| 超高（外轨抬高）通过 Instance 的旋转变换实现 | 避免为每根轨枕生成独立几何 |
| 曲线段 Instance 携带旋转角度和径向位移 | 沿圆心方向偏移 |
| 道岔、伸缩调节器、桥隧过渡段等非平直段退出 Instancing | 单独生成全精度几何 |

#### 2.4.4 性能预期

| 指标 | 全几何生成 | Instancing 模式 | 优化比 |
|------|-----------|----------------|--------|
| 单线 100km Draw Call | ~1,200,000 | ~1,200 | **~1000×** |
| 几何数据量 | ~50 GB | ~50 MB | **~1000×** |
| 加载时间 | >5 分钟 | <10 秒 | **可观** |

**Go 结构体**: `TrackInstanceConfig`, `SegmentGeometryParams`

# 第二部分：接触网体系（OCS）

## 1. 接触线与承力索

### 1.1 接触线

**关键字**: `TYPE=OCS_CW`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 型号 | `TYPE` | - | 例：CTHA-120, CTS-150 | - |
| 截面积 | `SectionalArea` | mm² | - | >0 |
| 标称直径 | `Diameter` | mm | - | >0 |
| 额定张力 | `RatedTension` | kN | 展放张力 | 10~40 |
| 最大允许张力 | `MaxTension` | kN | - | - |
| 单位长度质量 | `WeightPerMeter` | kg/m | - | >0 |
| 载流量 | `CurrentCapacity` | A | - | - |
| 弹性模量 | `ElasticModulus` | N/mm² | - | - |
| 线膨胀系数 | `ExpansionCoeff` | 1/℃ | - | - |

**建模要点：**
- 通用模型：以锚段为单位，沿 X 轴方向
- 接触线坡度变化处采用分段直线/折线描述
- 拉出值通过 Y 方向偏移实现
- 坐标原点：锚段起点接触线高度位置
**几何构成：**
**几何构成：**
1. 截面：顶部夹持面（半圆 R=2~3mm + 直边），中部梯形过渡，底部圆弧 R=6~10mm，两侧沟槽（深 2mm，宽 3mm）
2. `BRepBuilderAPI_MakeWire` 闭合 + `BRepBuilderAPI_MakeFace` + `BRepOffsetAPI_MakePipeShell` 沿锚段中心线扫掠
3. 铜合金色 R=204/G=102/B=0，中部梯形过渡，底部接触面（圆弧 R=6~10mm）+ 两侧沟槽（深 2mm，宽 3mm）
2. 顶部夹持面光滑 R=3mm 圆弧，底部接触面 R=8mm 大圆弧
3. 沟槽尖角 R0.5mm 圆角，避免应力集中
4. 沿锚段中心线 `BRepOffsetAPI_MakePipeShell` 扫掠
5. 铜合金色：R=204/G=102/B=0，金属光泽，接触面呈磨亮光泽（略浅）
6. 接头处 `BRepAlgoAPI_Common` 斜切 45° 接缝，使用 `BRepBuilderAPI_MakeWire` + `BRepBuilderAPI_MakeFace` 构建 2D 草图
2. 扫掠：沿锚段中心线（X 方向）做 `BRepOffsetAPI_MakePipeShell`，可处理多段折线衔接
3. 截面沟槽位于底部，两侧为接触面，顶部为夹持面
4. 拉出值通过在中心线的 Y 方向偏移叠加正弦波曲线实现
5. 导线坡度在 Z 方向渐变

**Go 结构体**: `ContactWireParams`

- 吊弦沿跨距以 `Spacing` 均布，长度由承力索与接触线的结构高度自动计算
- 每根吊弦 = 吊弦线 + 上端载流线夹 + 下端载流线夹 + 载流回路（导电型）
- 坐标原点：承力索与吊弦连接点
- 非导电型吊弦仅提供机械连接，不含载流回路

**几何构成（吊弦 = 吊弦线 + 载流线夹 + 载流回路）：**

**吊弦线：**
- `BRepBuilderAPI_MakeEdge` 从承力索底面到接触线顶面的垂直线段
- 长度 `Length` 随跨中至支柱位置变化（跨中最大，支柱点最小）
- `BRepOffsetAPI_MakePipe` 沿线段扫掠圆形截面，径 `WireDiameter/2`
- 可调吊弦在中间增加一个螺纹调节器（`MakeCylinder` 螺母+螺杆）

**载流线夹（上端/下端）：**
- 上端线夹：`MakeBox` 夹块 + 弧形槽 `Cut`（卡入承力索）+ 螺栓孔 `Cut`
- 下端线夹：`MakeBox` 夹块 + 弧形槽 `Cut`（卡入接触线）+ 螺栓孔 `Cut`
- 两线夹分别 `BRepAlgoAPI_Fuse` 于吊弦线两端

**载流回路（仅导电型）：**
- `Geom_BezierCurve` 沿吊弦路径 + 载流线夹外侧布设
- `BRepOffsetAPI_MakePipe` 扫掠载流线截面
- 多根并联时并行排列
- 与吊弦线合并为统一实体

**Go 结构体**: `DropperAssemblyParams` — 含吊弦线、载流线夹、载流回路的完整吊弦装配

## 2. 整体悬吊装置

腕臂底座、横担、腕臂管、承力索座、定位器、载流回路及线夹等集成为一个整体悬吊单元。每根支柱处安装一个悬吊单元，完成对接触线和承力索的支撑、定位和电气连通。

### 2.1 横担（Cross-arm）

**关键字**: `TYPE=OCS_CROSS_ARM`

固定于支柱顶部的水平钢架结构，由横梁（水平）和斜撑（竖直方向）两组钢架组成门型刚架。横担为腕臂提供安装基座，将接触网负载传递至支柱。适用于双叉臂（固定腕臂）形式的接触网悬挂。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-双叉臂固定横担, 2-三角撑横担, 3-桁架式横担 | 1~3 |
| 横梁长度 | `BeamLength` | mm | 水平横梁外缘全长 | >0 |
| 横梁截面高 | `BeamHeight` | mm | - | >0 |
| 横梁截面宽 | `BeamWidth` | mm | - | >0 |
| 横梁壁厚 | `BeamThickness` | mm | - | >0 |
| 斜撑长度 | `BraceLength` | mm | 竖直斜撑长度 | >0 |
| 斜撑截面 | `BraceSection` | mm | 斜撑截面规格 | - |
| 安装高度 | `MountHeight` | mm | 横担重心距轨面高度 | - |
| 螺栓孔间距 | `BoltSpacing` | mm | 与支柱连接螺栓孔 | - |
| 螺栓孔径 | `BoltDiameter` | mm | - | - |
| 螺栓数量 | `BoltCount` | 个 | - | ≥4 |
| 材质 | `Material` | - | Q235B, Q355B | - |
| 表面处理 | `SurfaceFinish` | - | 1-热镀锌, 2-涂装 | - |

**建模要点：**
- 横担为刚性钢架结构，由横梁（水平）和斜撑（竖向）两组钢架焊接或螺栓连接而成
- 横梁沿线路横向布置，斜撑连接横梁外端与支柱上部，形成三角形受力体系
- 横担上安装腕臂底座，承接腕臂系统
- 适用于双叉臂/固定腕臂形式的接触网悬挂
- 对于双线路腕臂，横担两侧对称悬挑
- 原点：横担与支柱连接面中心

**几何构成：**
1. 横梁主梁：`BRepPrimAPI_MakeBox` 矩形截面梁，四条竖棱 `BRepFilletAPI_MakeFillet` R3~R5 圆角
2. 斜撑杆：`BRepPrimAPI_MakeBox` 矩形截面 + `gp_Trsf` 旋转，两端 `BRepFilletAPI_MakeFillet` R4 圆角
3. 节点连接板：`BRepPrimAPI_MakeBox` 厚 12mm 三角形节点板，三边 R4 圆角
4. 横梁与斜撑合并 `BRepAlgoAPI_Fuse`，连接板与杆件 `Fuse`
5. 镀锌钢色 R=204/G=204/B=204
6. 原点：横担与支柱接触面中心，四条竖棱 `BRepFilletAPI_MakeFillet` 圆角 R3~R5，端部斜切角 15° 防应力集中
2. 斜撑杆：`BRepPrimAPI_MakeBox` + `gp_Trsf` 旋转，两端 `BRepFilletAPI_MakeFillet` 圆角，与横梁连接节点板 `BRepPrimAPI_MakeBox` 厚 12mm 三角形节点板，三边圆角
3. 螺栓连接：`BRepPrimAPI_MakeCylinder` 螺栓孔 `BRepPrimAPI_MakeCylinder` 阵列 `BRepAlgoAPI_Cut`
4. 焊缝：节点板与横梁/斜撑之间 `BRepPrimAPI_MakeCylinder` 连接线
5. 表面镀锌层：整体色 R=204/G=204/B=204，A=1.0，金属光泽
6. 分段标识：节段拼接处设 2mm 深刻线 `BRepAlgoAPI_Cut` 矩形槽，标示拼装位置
7. 原点，长 `BeamLength`，截面 `BeamWidth×BeamHeight`
2. 斜撑：`BRepPrimAPI_MakeBox` 斜撑杆，旋转至设计角度
3. `BRepAlgoAPI_Fuse` 合并为整体刚架
4. 连接板：`BRepPrimAPI_MakeBox` + 减螺栓孔
5. 安装法兰：`BRepPrimAPI_MakeBox` + 减孔
6. 以支柱轴线对称，Y 方向悬挑

**Go 结构体**: `CrossArmParams`

### 2.2 平腕臂（Level Cantilever）

水平放置的腕臂管，一端通过底座固定于横担，另一端悬挑。平腕臂上安装承力索座以支撑承力索。

**关键字**: `TYPE=OCS_CANT_LEVEL`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 长度 | `Length` | mm | 平腕臂总长 | >0 |
| 外径 | `OuterDiameter` | mm | 钢管外径 | >0 |
| 壁厚 | `WallThickness` | mm | 钢管壁厚 | >0 |
| 安装高度 | `MountHeight` | mm | 距轨面高度 | - |
| 水平仰角 | `RiseAngle` | ° | 水平管略向上倾斜角 | 0~5 |

**Go 结构体**: `LevelCantileverParams`
**几何构成：**
1. 主体：薄壁圆管，`BRepPrimAPI_MakeCylinder` 生成外圆柱，`BRepPrimAPI_MakeCylinder` 生成内圆柱，`BRepAlgoAPI_Cut` 得到管状
2. 管端斜切：`BRepAlgoAPI_Common` 与斜切平面求交，得到腕臂管端部45°斜切面
3. 两端焊接法兰盘或连接耳板：`BRepPrimAPI_MakeBox` 生成矩形板，布孔用 `BRepAlgoAPI_Cut` 切圆柱
4. 整体沿 X 轴水平放置，仰角通过旋转 `gp_Trsf` 施加
5. 原点：腕臂与底座连接孔中心

### 2.3 斜腕臂（Slanted Cantilever）

倾斜放置的腕臂管，下端通过底座固定于支柱，上端连接至平腕臂悬挑端。与平腕臂形成三角支撑结构。

**关键字**: `TYPE=OCS_CANT_SLANT`

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 长度 | `Length` | mm | 斜腕臂总长 | >0 |
| 外径 | `OuterDiameter` | mm | 钢管外径 | >0 |
| 壁厚 | `WallThickness` | mm | 钢管壁厚 | >0 |
| 安装倾角 | `SlantAngle` | ° | 相对铅垂线的倾斜角度 | 30~60 |

**Go 结构体**: `SlantCantileverParams`
**几何构成：**
1. 主体：薄壁圆管，构造方式同平腕臂 `Cylinder - Cylinder`
2. 两端斜切：斜切平面法向量与管轴线成安装倾角，用 `BRepAlgoAPI_Common` 实现
3. 上下端焊接连接耳板：`BRepPrimAPI_MakeBox` + 布尔减螺栓孔
4. 安装时绕 Y 轴旋转 `SlantAngle`，使上端指向平腕臂外端
5. 原点：斜腕臂下端底座连接孔中心

### 2.6 支柱连接座（Mast Mounting Bracket）

**关键字**: `TYPE=OCS_MAST_BRACKET`

固定于支柱上的金属连接件，用于安装棒式绝缘子和腕臂底座。在双叉臂系统中，通常设置上下两个连接座，分别对应平腕臂和斜腕臂的安装。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-单联座, 2-双联座, 3-可调式 | 1~3 |
| 安装孔间距 | `BoltSpacing` | mm | 与支柱连接的螺栓孔间距 | >0 |
| 安装孔径 | `BoltDiameter` | mm | - | - |
| 连接座高度 | `Height` | mm | 座体高度 | >0 |
| 连接座宽度 | `Width` | mm | 座体宽度 | >0 |
| 连接座厚度 | `Thickness` | mm | 钢板厚度 | ≥10 |
| 绝缘子安装孔间距 | `InsulatorBoltSpacing` | mm | 连接棒式绝缘子的孔距 | - |
| 绝缘子安装孔径 | `InsulatorBoltDiameter` | mm | - | - |
| 安装角度 | `MountAngle` | ° | 连接座倾斜角度 | 0~60 |

**建模要点：**
- 支柱连接座为焊接或铸造金属件，通过螺栓固定于工字带孔支柱腹板或钢柱法兰
- 双叉臂系统设置上下两个连接座：上连接座固定平腕臂棒式绝缘子，下连接座固定斜腕臂棒式绝缘子
- 连接座位置决定腕臂系统的安装高度和角度
- 原点：连接座与支柱接触面中心

**几何构成：**
1. 座体主体：`BRepPrimAPI_MakeBox` 矩形金属板，宽 `Width`×高 `Height`×厚 `Thickness`
2. 支柱安装螺栓孔：`BRepPrimAPI_MakeCylinder` × N，`BRepAlgoAPI_Cut` 阵列切除
3. 绝缘子安装耳板：座体外侧延伸出的两块平行耳板，`BRepPrimAPI_MakeBox` + 端部倒圆
4. 耳板孔：`BRepPrimAPI_MakeCylinder` 垂直穿过耳板，`BRepAlgoAPI_Cut`，`InsulatorBoltDiameter`×`InsulatorBoltSpacing`
5. 加劲肋：座体与支柱接触面之间的三角形肋板，`BRepPrimAPI_MakePrism` 拉伸三角形截面
6. 上下连接座结构对称，`MountAngle` 旋转使安装面朝向设计方向

**Go 结构体**: `MastBracketParams`

### 3.1 钢支柱（格构式/H型钢）

7. 拉线以直线表达

1. 基础主体：`BRepPrimAPI_MakeBox` 或 `BRepPrimAPI_MakeCylinder` 锥形台

3. 回填土示意：基础外围不建模，仅基础本体

**钻孔灌注桩基础（FOUND_BORED_PILE）：**
1. 桩身：`BRepPrimAPI_MakeCylinder` 长圆柱体
2. 桩顶扩大头：`BRepPrimAPI_MakeCone` 锥台 + `BRepAlgoAPI_Fuse`
3. 桩顶预埋件：法兰板 + 锚栓同法兰盘基础构造
4. 桩底扩底：`BRepPrimAPI_MakeCone` 倒锥台 + `Fuse`

**挖孔桩基础（FOUND_EXCAVATED_PILE）：**
1. 桩身：`BRepPrimAPI_MakeCylinder` 圆柱 + `BRepAlgoAPI_Fuse` 阶台
2. 护壁：`BRepPrimAPI_MakeCylinder` 外筒减内筒（壁厚 100~150mm）

**锚栓基础（FOUND_ANCHOR）：**
1. 锚杆：`BRepPrimAPI_MakeCylinder` 长杆 + 底部劈裂楔形
2. 承台板：`BRepPrimAPI_MakeBox` 垫板

### 7.1 软横跨（Head Span）

- 下部固定绳水平布置，连接各悬挂点下部，承托接触悬挂
- 绝缘子串串接在横向承力索/固定绳与支柱连接点之间
- 悬挂线夹位于各悬挂点，将接触悬挂固定于软横跨

**几何构成（导线模型参照 GIM TransmissionLineParams）：**
1. **横向承力索**：`Geom_BezierCurve` 定义上凸弧线（两端高、跨中低），`BRepOffsetAPI_MakePipe` 或 `BRepOffsetAPI_MakePipeShell` 扫掠圆形截面（径 `CrossCatenaryDia/2`），弧垂 `CrossCatenarySag`

3. **下部固定绳**：同上，在 Z 方向低于上部固定绳（间距由接触悬挂高度决定）
4. **绝缘子串**：每个支柱连接点处 `BRepPrimAPI_MakeCylinder` + `BRepPrimAPI_MakeCone` 伞裙阵列（参照 2.5），串接在横向承力索/固定绳与支柱之间，沿线路方向排列
5. **悬挂线夹**：每个 `HangPoint` 处 `MakeBox` 夹块 + 弧形槽 `Cut` `（径对应接触悬挂），BRepAlgoAPI_Fuse` 于横向承力索/固定绳交汇点
6. 图中以虚线示意各悬挂点到接触悬挂的垂直吊线（不建实体）

1. 参照 3.1 钢支柱或 3.2 混凝土支柱构造
2. 柱顶设连接法兰，柱身 `MakeBox` 或格构式
3. 外倾 `MastLeanAngle` 通过 `gp_Trsf` 旋转

**连接节点：**
1. `BRepPrimAPI_MakeBox` 节点板 + 螺栓孔 `BRepPrimAPI_MakeCylinder` `Cut`
2. 法兰盘 `BRepPrimAPI_MakeBox` + 螺栓 `BRepPrimAPI_MakeCylinder`
3. 梁端与柱顶 `BRepAlgoAPI_Fuse` 合并为整体刚架

## 7. 张力补偿装置

锚段两端设置自动张力补偿装置，用于保持接触线和承力索的张力恒定。铁路接触网常见型式包括棘轮补偿装置和滑轮补偿装置。

### 7.1 棘轮补偿装置（Ratchet Compensator）

**关键字**: `TYPE=OCS_RATCHET_COMP`

棘轮补偿装置利用大直径棘轮产生机械力臂差实现张力补偿，广泛应用于高速铁路。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 型号 | `Type` | - | 例：JLB-1, JLB-2 | - |
| 补偿方式 | `CompMethod` | - | 1-单棘轮, 2-双棘轮 | 1~2 |
| 额定张力 | `RatedTension` | kN | 设计补偿张力 | 10~40 |
| 补偿行程 | `StrokeLength` | mm | 坠砣最大行程 | 1000~2000 |
| 传动比 | `TransmissionRatio` | - | 棘轮杠杆比 | 1:3 ~ 1:5 |
| 棘轮直径 | `WheelDiameter` | mm | 棘轮节圆直径 | >0 |
| 棘轮宽度 | `WheelWidth` | mm | - | >0 |
| 补偿绳规格 | `WireRopeSpec` | - | 钢丝绳直径 | - |
| 补偿绳长度 | `WireRopeLength` | mm | - | - |
| 坠砣数量 | `WeightCount` | 块 | 坠砣块数 | - |
| 坠砣单重 | `WeightPerBlock` | kg | 每块重量 | 25~50 |
| 坠砣总重 | `TotalWeight` | kg | 总补偿力 | - |
| 坠砣杆直径 | `WeightRodDiameter` | mm | - | >0 |
| 安装柱号 | `MastNo` | - | 关联锚柱编号 | - |
| 补偿方向 | `CompDirection` | - | 1-大里程, 2-小里程 | 1~2 |
| 制动装置 | `HasBrake` | bool | 是否带制动棘爪 | - |
| 防护罩 | `HasCover` | bool | 是否带防护罩 | - |

**几何构成：**
1. **棘轮主体**：`BRepPrimAPI_MakeCylinder` 大直径圆盘，径 `WheelDiameter`，厚 `WheelWidth`
2. **齿槽**：`BRepPrimAPI_MakeBox` 小凹槽沿圆周阵列，`BRepAlgoAPI_Cut`，齿数按直径比例 20~40 齿
3. **补偿绳槽**：`BRepAlgoAPI_Cut` 环形槽，槽宽对应绳径
4. **中心轴孔**：`BRepPrimAPI_MakeCylinder` 贯通，`BRepAlgoAPI_Cut`
5. **减重孔**：圆盘上均布减重孔，`BRepAlgoAPI_Cut` 沿圆周阵列
6. **制动棘爪**：`BRepPrimAPI_MakeBox` 棘爪块 + 楔形啮合端 `BRepAlgoAPI_Cut`
7. **安装支架**：`BRepPrimAPI_MakeBox` 支座板 + 加劲肋，固定于支柱
8. **防护罩**：`BRepPrimAPI_MakeBox` 半包围壳体，`BRepFilletAPI_MakeFillet` 边缘倒圆

**建模要点：**
- 棘轮本体为带有齿槽结构的圆盘，齿槽用于制动
- 补偿绳从棘轮两侧引出，一侧连接绝缘子串（导线端），一侧连接坠砣
- 坠砣串沿坠砣杆垂直排列，可在一定范围内上下滑动
- 制动棘爪在断线时卡住棘轮防止坠砣坠落
- 防护罩为半包围金属壳体
- 原点：棘轮中心安装轴

**组件结构：**
```
棘轮补偿装置
 ├─ 棘轮本体（RatchetWheel）— 大直径齿槽圆盘
 ├─ 补偿绳（CompensatorRope）— 钢丝绳，走两轮
 │   ├─ 导线端 → 绝缘子串 → 下锚金具 → 接触线/承力索
 │   └─ 坠砣端 → 坠砣杆 → 坠砣串
 ├─ 制动棘爪（BrakePawl）
 ├─ 防护罩（ProtectiveCover）
 ├─ 坠砣杆（WeightRod）
 └─ 坠砣串（WeightStack）— N 块×单重
```

**Go 结构体**: `RatchetCompensatorParams`

**关键字**: `TYPE=OCS_PULLEY_COMP`

| 滑轮直径 | `PulleyDiameter` | mm | 滑轮节圆直径 | >0 |
| 滑轮槽宽 | `GrooveWidth` | mm | 绳槽宽度 | - |
| 轮数 | `PulleyCount` | 个 | 定/动滑轮个数 | - |
| 补偿绳规格 | `WireRopeSpec` | - | 钢丝绳直径 | - |
| 补偿绳长度 | `WireRopeLength` | mm | - | - |
| 坠砣数量 | `WeightCount` | 块 | 坠砣块数 | - |
| 坠砣单重 | `WeightPerBlock` | kg | 每块重量 | 25~50 |
| 坠砣总重 | `TotalWeight` | kg | - | - |
| 坠砣杆直径 | `WeightRodDiameter` | mm | - | >0 |
| 转向轮 | `HasDeflectorPulley` | bool | 是否带转向轮 | - |
| 限制架 | `HasLimitFrame` | bool | 是否带坠砣限制架 | - |
| 安装柱号 | `MastNo` | - | 关联锚柱编号 | - |
| 补偿方向 | `CompDirection` | - | 1-大里程, 2-小里程 | 1~2 |

**几何构成：**
1. 定滑轮：`BRepPrimAPI_MakeCylinder` 盘体 + `BRepAlgoAPI_Cut` 环形绳槽，槽底半圆 R=绳径+1mm
2. 动滑轮：同构造，`BRepAlgoAPI_Cut` 减重孔 4 个
3. 中心轴孔 `BRepPrimAPI_MakeCylinder` 贯通
4. 补偿绳、转向轮、限制架、安装支架等见原步骤
5. 铸造色 R=130/G=130/B=130 + `BRepAlgoAPI_Cut` 环形绳槽，槽底半圆 R=绳径+1mm，槽边 `BRepFilletAPI_MakeFillet` R1，中心轴孔+滚动轴承内圈可见
2. **动滑轮**：同构造，质量轻于定滑轮（`BRepAlgoAPI_Cut` 减重孔 4 个）
3. **轴端挡圈**：`BRepPrimAPI_MakeBox` 环形板 + 定位螺栓
4. **轴承密封盖**：`BRepPrimAPI_MakeCylinder` 薄端盖，印有型号标记
5. **滑轮铸造**：色 R=130/G=130/B=130 球墨铸铁
6. 其余见原几何构成步骤 4-7
，槽宽 `GrooveWidth`；中心轴孔 `BRepAlgoAPI_Cut`
2. **动滑轮**：同定滑轮构造，位置随坠砣升降沿 Z 平移（`gp_Trsf` 设置 `StrokeLength` 范围内）
3. **滑轮组支架**：`BRepPrimAPI_MakeBox` 座体 + 销轴孔 `Cut`
4. **补偿绳**：`Geom_BezierCurve` 定滑轮与动滑轮之间的穿绕路径，`BRepOffsetAPI_MakePipe` 沿路径扫掠圆形截面（径 `WireRopeSpec/2`），穿绕次数 = `TransmissionRatio × 2`
5. **转向轮**（`HasDeflectorPulley`）：`BRepPrimAPI_MakeCylinder` 小滑轮 + 支架 `MakeBox`，布置于补偿绳转折处
6. **限制架**（`HasLimitFrame`）：`BRepPrimAPI_MakeBox` 矩形框架 + 开槽 `Cut`，包围坠砣串，限制横向摆动
7. **安装支架**：`BRepPrimAPI_MakeBox` 连接板 + 加劲肋 `BRepAlgoAPI_Fuse`，固定于支柱

**建模要点：**
- 滑轮组由定滑轮（固定于支柱）和动滑轮（随坠砣升降）组成
- 补偿绳穿绕方式由传动比决定
- 坠砣限制架防止坠砣横向摆动
- 转向轮用于改变补偿绳方向（空间受限时）
- 原点：定滑轮轴心

**组件结构：**
```
滑轮补偿装置
 ├─ 定滑轮组（FixedPulleyArray）— 固定于支柱上
 ├─ 动滑轮组（MovablePulleyArray）— 随坠砣移动
 ├─ 补偿绳（CompensatorRope）
 ├─ 转向轮（DeflectorPulley）
 ├─ 限制架（LimitFrame）
 ├─ 坠砣杆（WeightRod）
 └─ 坠砣串（WeightStack）
```

**Go 结构体**: `PulleyCompensatorParams`

### 7.3 补偿装置组件

#### 8.3.1 坠砣（Balance Weight Block）

**关键字**: `TYPE=OCS_BALANCE_WEIGHT`

单片坠砣，串装于坠砣杆上构成坠砣串，提供重力补偿力。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-混凝土坠砣, 2-铸铁坠砣 | 1~2 |
| 宽度 | `Width` | mm | 坠砣宽度 | >0 |
| 厚度 | `Thickness` | mm | 坠砣厚度 | >0 |
| 高度 | `Height` | mm | 坠砣高度（单块） | >0 |
| 重量 | `Weight` | kg | 单块重量 | 25~50 |
| 中心孔径 | `CenterHoleDiameter` | mm | 穿坠砣杆用 | >坠砣杆径 |

**建模要点：**
- 坠砣为矩形或圆形混凝土/铸铁块，中心预留通孔
- 多块坠砣串装于坠砣杆上，块与块之间叠放
- 最下方一块坠砣由坠砣杆底部挡板或螺母托住

**几何构成：**
1. 主体：`BRepPrimAPI_MakeBox` 矩形块，宽×厚×高
2. 中心孔：`BRepPrimAPI_MakeCylinder` 垂直通孔，`BRepAlgoAPI_Cut`
3. 棱边倒角：`BRepFilletAPI_MakeFillet` R5~R10
4. 吊耳：顶部 `BRepPrimAPI_MakeBox` 耳板 + 圆孔
5. 混凝土色 R=195/G=195/B=195，铸铁色 R=160/G=150/B=140

#### 8.3.5 下锚金具（Anchor Fittings）

接触线/承力索下锚端与补偿绳之间的连接金具。

**关键字**: `TYPE=OCS_ANCHOR_FITTING`

| 参数 | 关键字 | 单位 | 说明 |
|------|--------|------|------|
| 类型 | `Type` | - | 1-杵环杆, 2-双耳连接器, 3-楔形线夹 |
| 长度 | `Length` | mm | >0 |
| 直径/规格 | `Spec` | mm | - |
| 破坏荷载 | `FailureLoad` | kN | - |

**建模要点：**
- 杵环杆一端连接补偿绳，另一端通过双耳与绝缘子串连接
- 双耳连接器用于延长或转向，两侧均为叉形接头
- 楔形线夹通过楔块锁紧导线，无需压接工具

**几何构成：**

**杵环杆（Type=1）：**
1. 杆体：`BRepPrimAPI_MakeCylinder` 圆钢杆，长 `Length`，径 `Spec`
2. 杵头：`BRepPrimAPI_MakeSphere` 球头，与杆体 `BRepFilletAPI_MakeFillet` R3 过渡
3. U 形环：`BRepOffsetAPI_MakePipe` 沿 U 形路径扫掠圆形截面，环口 R5 过渡
4. 整体沿 X 轴方向

**双耳连接器（Type=2）：**
1. 主体：`BRepPrimAPI_MakeBox` 矩形连接块，棱角 `BRepFilletAPI_MakeFillet` R3
2. 双耳板：两侧凸出耳板 + 端部 R5 圆角
3. 销孔：`BRepPrimAPI_MakeCylinder` 横向穿过耳板，`BRepAlgoAPI_Cut`

**楔形线夹（Type=3）：**
1. 线夹体：`BRepPrimAPI_MakeBox` 锥形块，外棱 R3 圆角，内腔楔形面
2. 楔块：独立 `BRepPrimAPI_MakeBox` 楔块，从侧面滑入
3. 导线槽：内腔 `BRepAlgoAPI_Cut` 半圆弧槽，两端 `BRepFilletAPI_MakeFillet` R2 过渡
2. 杵头：`BRepPrimAPI_MakeSphere` 球头 + `BRepFilletAPI_MakeFillet` 与杆体过渡 R3
3. U 形环：`BRepOffsetAPI_MakePipe` 沿 U 形路径扫掠圆形截面，环口处弧形过渡 R5
4. 镀锌表面：R=204/G=204/B=204，金属拉丝纹理（细微轴向纹路插值）

**双耳连接器（Type=2）：**
1. 主体：`BRepPrimAPI_MakeBox` 矩形连接块，棱角 `BRepFilletAPI_MakeFillet` R3
2. 双耳板：两侧凸出耳板 `BRepFilletAPI_MakeFillet` R5 端部圆角
3. 销孔：`BRepPrimAPI_MakeCylinder` + 开口销孔 `BRepAlgoAPI_Cut`
4. 镀锌，同上

**楔形线夹（Type=3）：**
1. 线夹体：`BRepPrimAPI_MakeBox` 锥形块，外棱 R3 圆角，内腔楔形面
2. 楔块：独立 `BRepPrimAPI_MakeBox` 楔块，从侧槽滑入，表面刻横纹防滑 `BRepAlgoAPI_Cut`
3. 导线槽：内腔 `BRepAlgoAPI_Cut` 半圆槽 + U 型螺栓贯穿
4. 可锻铸铁色：R=140/G=135/B=130
，长 `Length`，直径 `Spec`
2. 杵头（一端）：`BRepPrimAPI_MakeSphere` 球头 + `BRepAlgoAPI_Fuse` 焊接于杆端
3. 圆环（另一端）：`BRepPrimAPI_MakeCylinder` 弯曲成 U 形环，`BRepOffsetAPI_MakePipe` 扫掠圆形截面沿 U 形路径，与杆体 `Fuse`
4. 整体沿 X 轴方向

**双耳连接器（Type=2）：**
1. 主体：`BRepPrimAPI_MakeBox` 矩形连接块，长 `Length`，宽/高由 `Spec` 定
2. 两端叉耳：`BRepPrimAPI_MakeBox` 凸出耳板 ×2，端部 `BRepFilletAPI_MakeFillet` 倒圆
3. 叉耳销孔：`BRepPrimAPI_MakeCylinder` 横向穿过耳板，`BRepAlgoAPI_Cut`
4. 中心减重孔：杆体中部 `BRepPrimAPI_MakeCylinder` 纵向孔，`BRepAlgoAPI_Cut`

**楔形线夹（Type=3）：**
1. 线夹主体：`BRepPrimAPI_MakeBox` 锥形块，上宽下窄，内腔为楔形槽
2. 楔块：`BRepPrimAPI_MakeBox` 楔形块，可从主体侧面滑入
3. 导线槽：主体内 `BRepAlgoAPI_Cut` 半圆弧槽（半径对应导线外径）
4. U 型螺栓：`BRepPrimAPI_MakeCylinder` 螺栓 + 螺母，`BRepAlgoAPI_Cut` 切出螺纹孔

**Go 结构体**: `AnchorFittingParams`

| 支架长度 | `BracketLength` | mm | 沿线路方向宽度 |
| 支架宽度 | `BracketWidth` | mm | 垂直方向宽度 |
| 角钢规格 | `AngleSpec` | - | 支架用角钢型号 |
| 固定螺栓间距 | `BoltSpacing` | mm | - |
| 固定螺栓直径 | `BoltDiameter` | mm | - |

**建模要点：**
- 横担式：水平角钢/槽钢从支柱侧面悬挑，用于架空悬挂附加导线
- 壁挂式：平板直接固定于支柱壁面，导线沿支柱敷设
- 双支柱式：跨越两组支柱间悬挂

**几何构成（按类型分述）：**

**横担式（Type=1）：**
1. 主梁：`BRepPrimAPI_MakeBox` 角钢截面（`AngleSpec`），长 `OverhangLength`，沿 Y 方向水平悬挑
2. 斜撑（可选）：`BRepPrimAPI_MakeBox` 斜撑杆，从主梁外端斜向下连接支柱，`gp_Trsf` 旋转至设计角度
3. 支柱连接板：`BRepPrimAPI_MakeBox` 矩形连接板 + 螺栓孔 `BRepPrimAPI_MakeCylinder` `Cut`（`BoltSpacing`×`BoltDiameter`）
4. 挂线点：主梁外端 `BRepPrimAPI_MakeBox` 小耳板 + 圆孔 `Cut`，用于连接绝缘子
5. `BRepAlgoAPI_Fuse` 合并主梁 + 斜撑 + 连接板

**壁挂式（Type=2）：**
1. 壁板：`BRepPrimAPI_MakeBox` 矩形平板，长 `BracketLength`×宽 `BracketWidth`，贴合支柱壁面安装
2. 安装螺栓孔：`BRepPrimAPI_MakeCylinder` × 4 角部孔，`BRepAlgoAPI_Cut`
3. 挂线耳板：壁板外侧焊接 `BRepPrimAPI_MakeBox` 耳板 + 圆孔 `Cut`

**双支柱式（Type=3）：**
1. 横梁：`BRepPrimAPI_MakeBox` 在两个支柱之间水平跨越，长 = 支柱间距
2. 两端连接座：`BRepPrimAPI_MakeBox` 连接板 + 螺栓孔 `Cut`，固定于两侧支柱
3. 挂线点：沿横梁按 `BracketLength` 间距均布

**Go 结构体**: `AuxBracketParams`

# 第三部分：轨道体系

## 1. GeoJSON Polyline 与轨道模型映射

轨道系统的空间数据以 **GeoJSON LineString/Polyline** 表达线路中心线，通过 Feature 的 `properties` 携带区段属性。各 Polyline 段映射到对应的参数化组件：

### 1.1 映射规则

```
GeoJSON FeatureCollection
 ├─ Feature[0]: LineString  ───────────────────────→ 区间正线（直/曲线段）
 │   properties: { "type": "mainline", "rail": "60kg", "gauge": 1435, "superElevation": 0~180 }
 │
 ├─ Feature[1]: LineString  ───────────────────────→ 桥隧过渡段（加密扣件+护轨）
 │   properties: { "type": "bridge", "sleeperSpacing": 500, "hasGuardRail": true }
 │
 ├─ Feature[2]: MultiLineString  ───────────────────→ 道岔
 │   coordinates: [ [主线polyline], [侧线polyline] ]
 │   properties: { "type": "turnout", "hand": "left", "no": 12, "frog": "fixed" }
 │
 ├─ Feature[3]: Point  ────────────────────────────→ 钢轨伸缩调节器
 │   properties: { "type": "expansionJoint", "capacity": "±400" }
 │
 └─ Feature[4]: Point  ────────────────────────────→ 减速顶/车挡等
     properties: { "type": "retarder", "count": 12, "spacing": 1000 }
```

### 1.2 区段类型与参数化组件对应

| GeoJSON `type` | 参数化组件 | 扫掠方式 |
|----------------|-----------|----------|
| `"mainline"` | `RailProfile` 沿折线扫掠 | 直线用 `MakePrism`，圆曲线用旋转矩阵逐段 |
| `"mainline"` (含 `superElevation`) | 同上 + 外轨绕内轨抬高 | Instance 矩阵带绕 X 轴旋转分量 |
| `"bridge"` | 同 mainline + 两侧 `GuardRailProfile` | 护轨与基本轨 Y 向偏移 `GuardOffset` |
| `"turnout"` | `TurnoutParams` → 单开/对称/交叉渡线 | 岔心对准 MultiLineString 分岔点，曲股按导曲线半径扫掠 |
| `"expansionJoint"` | `ExpansionJointParams` | 基本轨 + 尖轨变截面，置于 Point 坐标处 |
| `"retarder"` | `RetarderParams` | 沿轨底阵列 `MakeBox`，置于 Point 坐标处 |

### 1.3 折线到连续钢轨的拆分

GeoJSON 的 LineString 坐标序列为 `[[x1,y1,z1], [x2,y2,z2], ...]`，映射时按以下规则拆分：

| 相邻段几何关系 | 判定条件 | 处理 |
|---------------|----------|------|
| 直线段 | 三点共线（叉积≈0） | 整段 `MakePrism`，每 25m/100m 插入轨缝 |
| 圆曲线段 | 三点同圆（曲率半径恒定） | 旋转矩阵增量扫掠，每 10~25m 一段 |
| 缓和曲线 | 曲率线性变化 | 逐段计算曲率半径，分段旋转扫掠 |
| 道岔分岔点 | `type="turnout"` 的 MultiLineString | 岔心对齐分岔点，曲股/直股分别生成 |
| 离散跳跃点 | 相邻点间距 > 50m | 视为轨道中断（如站场缺口），不连接 |

### 1.4 GeoJSON Properties → 组件参数映射

```json
// 区间正线
{
  "type": "mainline",
  "rail": "60kg",           // → RailProfileParams.Type = 60kg/m
  "gauge": 1435,            // → RailAlignmentParams.Gauge
  "superElevation": 80,     // → RailAlignmentParams.SuperElevation (mm)
  "sleeperType": "III",    // → SleeperParams.Type
  "sleeperSpacing": 600,   // → SleeperParams.Spacing
  "fastenerType": "WJ-8",  // → FastenerParams.Type
  "layer": 0               // → Z 层偏移（多层站场）
}

// 道岔
{
  "type": "turnout",
  "hand": "left",          // → TurnoutParams.Hand = 1-左开
  "no": 12,                // → TurnoutParams.TurnoutNo → FrogAngle = arctan(1/N)
  "switchType": "curved",  // → TurnoutParams.SwitchType = 2-曲线尖轨
  "frog": "fixed"          // → FrogCalculatedParams 定型辙叉
}
```

### 1.5 扫掠方法对照

| GeoJSON 段 | OCC 操作 |
|------------|----------|
| 直线 | `GP->MakePrism(RailSection, gp_Vec(dx,0,0), length)` |
| 圆曲线 | `gp_Trsf.SetRotation(center, Z, stepAngle)` 逐段变换 Instance |
| 缓和曲线 | 每 5m 计算曲率半径，`gp_GTrsf` 局部旋转 |
| 道岔 | 岔心 `BRepAlgoAPI_Fuse` 直股+曲股+辙叉+护轨+岔枕 |
| 超高段 | Instance 矩阵增加绕 X 轴旋转 (superElevation / gauge) |

> GeoJSON 不包含轨枕/扣件的独立坐标——它们由线路中心线 + `SleeperSpacing` 自动生成，通过 Instance 变换矩阵（X 偏移=间距×序号，Y 偏移=±gauge/2，Z 旋转=超高量）批量渲染。

### 8.2 辙叉自动计算（Frog Auto Calculation）

辙叉是道岔的关键部件，通过道岔号数 N 自动计算辙叉角、辙叉长度、有害空间等全部派生参数。

#### 7.2.1 辙叉角与道岔号数关系

辙叉角 α（Frog Angle）与道岔号数 N 的关系：

```
N = cot(α) = 1 / tan(α)
α = arctan(1 / N)
```

**标准道岔号数与辙叉角对照表：**

| 道岔号数 N | 辙叉角 α | 导曲线半径 R (m) | 侧向通过速度 (km/h) |
|-----------|----------|-----------------|-------------------|
| 9号 | 6°20′25″ | 180~200 | 35 |
| 12号 | 4°45′49″ | 350~380 | 50 |
| 18号 | 3°10′47″ | 800~1100 | 80 |
| 30号 | 1°54′33″ | 2700~3500 | 140 |
| 42号 | 1°21′50″ | 5000~6200 | 160 |
| 62号 | 0°55′30″ | 8200~10000 | 220 |

#### 7.2.2 辙叉计算参数

| 输出参数 | 关键字 | 单位 | 计算公式 / 来源 |
|----------|--------|------|----------------|
| 辙叉角 | `FrogAngle` | ° | α = arctan(1/N) |
| 辙叉全长 | `FrogTotalLength` | mm | N × 轨距系数 |
| 辙叉心轨长度 | `FrogPointLength` | mm | 由钢轨类型和辙叉号数查表 |
| 翼轨长度 | `WingRailLength` | mm | 翼轨直段+弯折段 |
| 翼轨弯折点位置 | `WingBendPos` | mm | 距辙叉理论中心 |
| 有害空间 | `DeadSpace` | mm | 翼轨与心轨轨头间缝隙 |
| 护轨轮缘槽宽 | `GuardFlangeGroove` | mm | 42~48（由轨距和辙叉角计算） |
| 护轨开口段长度 | `GuardOpenLength` | mm | 护轨引导段长度 |
| 辙叉轨距 | `FrogGauge` | mm | 标准 1435 + 加宽量 |
| 辙叉咽喉宽度 | `ThroatWidth` | mm | 两翼轨间最小净距 |
| 辙叉心轨尖端宽度 | `PointTipWidth` | mm | 心轨理论尖端宽（0~10mm） |
| 辙叉心轨工作边长度 | `PointWorkLength` | mm | 心轨轨头工作边展开长 |

**自动计算逻辑（伪码）：**
```
function CalculateFrog(turnoutNo, railType):
  // 1. 查表或计算辙叉角
  frogAngle = arctan(1 / turnoutNo)
  
  // 2. 根据道岔号数和钢轨类型确定导曲线半径
  leadCurveRadius = LookupCurveRadius(turnoutNo)
  
  // 3. 计算有害空间
  deadSpace = (guardRailGauge - 2 × railHeadWidth) / tan(frogAngle)
  
  // 4. 计算辙叉心轨长度（查表）
  pointLength = LookupPointLength(turnoutNo, railType)
  
  // 5. 计算翼轨长度
  wingLength = pointLength + wingExtension
  
  // 6. 计算护轨轮缘槽宽度
  guardGroove = CalculateGuardGroove(gauge, frogAngle)
  
  // 7. 标出道岔全长
  totalLength = LookupTotalLength(turnoutNo)
  
  return FrogGeometry{
    frogAngle, totalLength, leadCurveRadius, deadSpace,
    pointLength, wingLength, guardGroove, ...
  }
```

#### 8.3.5 曲线尖轨装配规则

```
左开道岔曲线尖轨装配：
  直基本轨（直线）  +   直尖轨（直线可动）
  曲基本轨（曲线弯折） + 曲尖轨（曲线可动）
                      ↓
  侧股方向 ← 曲基本轨与曲尖轨共同形成导曲线

右开道岔曲线尖轨装配：
  直基本轨（直线）  +   曲尖轨（曲线可动）
  曲基本轨（曲线弯折） + 直尖轨（直线可动）
                      ↓
  侧股方向 → 曲基本轨与曲尖轨共同形成导曲线
```

**建模要点：**
- 曲基本轨按导曲线半径在厂内预弯，轨头工作边为曲线线型
- 曲尖轨尖端刨削成极薄截面（趋近0mm），与曲基本轨贴合
- 尖轨跟端为固定端，通过间隔铁与连接轨或导曲线轨连接
- 尖轨动程（扳动量）一般为 120~180mm
- 左开和右开为镜像对称关系，几何尺寸一致
- 原点：道岔理论中心（岔心）

**Go 结构体**: `CurvedSwitchParams`, `TurnoutHandConfig`

### 11.2 减速顶（Retarder）

**关键字**: `TYPE=TRACK_RETARDER`

安装于钢轨内侧或外侧的液压/摩擦式减速装置，用于在编组场（驼峰）或特定区段控制车辆溜放速度，防止冲撞。

| 参数 | 关键字 | 单位 | 说明 | 约束 |
|------|--------|------|------|------|
| 类型 | `Type` | - | 1-液压减速顶, 2-摩擦减速顶, 3-可控减速顶 | 1~3 |
| 安装方式 | `MountType` | - | 1-轨内侧, 2-轨外侧, 3-双轨双侧 | 1~3 |
| 制动方式 | `BrakeMethod` | - | 1-单侧制动, 2-双侧制动 | 1~2 |
| 减速顶高度 | `Height` | mm | 顶面高出轨面高度 | 50~120 |
| 减速顶长度 | `Length` | mm | 沿钢轨方向长度 | >0 |
| 减速顶宽度 | `Width` | mm | 垂直于钢轨方向宽度 | >0 |
| 制动功 | `BrakingWork` | kJ | 单次制动做功能力 | - |
| 制动速度范围 | `SpeedRange` | km/h | 有效制动速度区间 | 0~30 |
| 复位方式 | `ResetMethod` | - | 1-液压自动复位, 2-弹簧复位, 3-手动复位 | 1~3 |
| 工作介质 | `Medium` | - | 1-液压油, 2-摩擦片 | 1~2 |
| 环境温度范围 | `TempRange` | ℃ | 工作温度 | -40~70 |
| 适用轨型 | `RailType` | - | 50/60/75kg/m | - |
| 安装间距 | `Spacing` | mm | 相邻减速顶中心距 | - |
| 数量 | `Count` | 个 | 单组减速顶安装数量 | - |
| 重量 | `Weight` | kg | 单台重量 | - |

**建模要点：**
- 减速顶主体为矩形或圆形块状结构，安装于钢轨轨底两侧
- 顶面高出轨面一定高度，通过车轮压触产生制动阻力
- 液压式顶部有活塞/柱塞结构，受压时油液节流产生阻力
- 沿钢轨方向按设计间距连续布置形成减速区段
- 双轨双侧布置时，左右股对称安装
- 原点：减速顶底座安装面中心



**几何构成：**
1. 防爬器：`BRepPrimAPI_MakeBox` 主体 + `BRepPrimAPI_MakeCylinder` 弹簧/穿销
2. 轨距拉杆：`BRepPrimAPI_MakeCylinder` 圆钢杆 + 两端螺纹 + 螺母
3. 以 `Spacing` 沿钢轨方向布置

**Go 结构体**: `RetarderParams`
