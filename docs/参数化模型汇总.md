# 通用规范

本章汇总三份 GIM 标准中跨专业共用的几何建模规范、坐标系约定、约束条件和文件格式要求。

## 1. 坐标系与单位

| 项目 | 规范要求 |
|------|----------|
| 坐标系 | **右手空间直角坐标系（Right-hand Cartesian）** |
| 模型比例 | **1:1** |
| 长度单位 | **毫米（mm）** |
| 地理坐标系 | **CGCS2000（2000国家大地坐标系）** |
| 高程基准 | **1985国家高程基准** |
| 坐标轴 | **Z轴向上（铅垂），X轴沿横担方向，Y轴垂直于X（线路方向）** |
| 角度单位 | **度（decimal degrees）**，特殊说明除外 |

## 2. 模型分类

| 模型类别 | 说明 | 适用阶段 | 文件格式 |
|----------|------|----------|----------|
| 通用模型（Universal） | 最大占位外形尺寸 + 主要技术参数 | 初步设计 | `*.mod` |
| 产品模型（Product） | 实际产品外形、安装、接口、附属信息 | 施工图/竣工图 | `*.mod` 或 `*.stl` |
| 装配模型（Process） | 含安装、加工、配筋等详细信息 | 施工图 | `*.stl` |

**建模原则：**
- 统一度量单位、统一属性定义、统一建模规则、统一层级划分、统一分类与编码
- 通用模型和产品模型应采用统一的配色标准
- 产品模型的几何细度应满足三维空间布置协同需求

## 3. 模型原点约定

### 3.1 架空线路

| 模型 | 原点位置 |
|------|----------|
| 杆塔（桁架塔） | 最长腿所在水平面的几何中心 |
| 杆塔（输电杆） | 杆底几何中心 |
| 基础 | 基础模型顶面中心 |
| 地脚螺栓 | 基础顶面与螺栓交汇处 |
| 插入角钢/钢管 | 基础顶面与角钢/钢管交汇处 |
| 绝缘子串 | 绝缘子串与杆塔连接点；多挂点时取最高挂点水平面与挂线点中心铅垂线交点 |
| 通道地物 | 相对于铁塔中心桩 |

### 3.2 电缆线路

| 模型 | 原点位置 |
|------|----------|
| 中间接头 | 几何中心点 |
| 光缆接头盒 | 几何中心点 |
| 电缆终端 | 下端子顶部中心点 |
| 接地箱/交叉互联箱 | 几何中心点 |
| 电缆夹具 | 底部中心点 |
| 电缆支架 | 根部上角点 |
| 电缆立柱 | 立柱底面中心点 |
| 接地扁铁 | 图形中心点 |
| 预埋件 | 与墙体连接部分根部点 |
| U型拉环 | 根部中心点 |
| 吊攀 | 根部中心点 |
| 直线井 | 井底面中心 |
| 四通井 | 井底面中心 |
| 排管 | 排管断面图中心 |
| 电缆通道（通用） | 断面原点位置因通道类型而异 |
| 管枕 | 管枕中心 |
| 独立终端平台 | 中间支架/立柱所在水平面的几何中心 |
| 柱式终端 | 支柱底面几何中心点 |

## 4. 文件格式

### 4.1 GIM 文件包结构（T/CEC 5055-2021）

```
*.GIM (7Z压缩)
├── 文件头 (元数据：文件标识、名称、创建时间、版本号)
└── 存储域
    ├── CBM/       组装模型 (*.cbm)、属性 (*.fam)、逻辑 (*.sch)、补充材料单 (*.xml)
    ├── DEV/       物理模型 (*.dev)、IFC (*.ifc)、属性 (*.fam)、ICD (*.icd)、IPCD (*.ipcd)、CPCD (*.cpcd)
    ├── PHM/       几何模型组 (*.phm)
    └── MOD/       几何模型 (*.mod / *.stl)
```

### 4.2 文件编码与标识

| 项目 | 要求 |
|------|------|
| 编码 | UTF-8（无 BOM） |
| 唯一标识 | GUID（128位） |
| 注释 | `//` 行注释 |
| 层级引用 | 按图 4.0.8 单向引用，禁止自引用 |
| 属性格式 | `标识符=值`，每行一个 |

### 4.3 几何模型文件格式

**基本图元格式（*.mod）：**
```
对象名 参数1=值 参数2=值 ...
```
示例：`Cuboid L=100 W=50 H=20`

**颜色表达：** RGBA，R/G/B 值域 0~255，A 值域 0~1

**空间变换矩阵：** 4×4 齐次矩阵，先行后列存储

**布尔运算：**
- `Union` — 并集
- `Intersection` — 交集
- `Difference` — 差集

**文件层级管理：** 分 5 级（F1System ~ F5System）

## 5. 杆塔建模规范

### 5.1 数据标识

| 标识 | 含义 | 格式 |
|------|------|------|
| P | 节点信息 | `P,节点号,X,Y,Z` |
| R | 杆件信息 | `R,节点1,节点2,规格,材质,...` |
| G | 挂点信息 | `G,挂点类型,挂点名称,X,Y,Z` |

### 5.2 多段标识

| 关键字 | 说明 |
|--------|------|
| Body | 本体（多个接腿共用的塔身、横担、塔头） |
| Leg | 接腿（无长短腿时含全部节点；有长短腿时仅含共用节点） |
| SubLeg | 子腿（长短腿的单独段） |
| H | 呼高标识：`H,呼高值,接身编号,接腿编号` |

### 5.3 挂点命名规则

| 挂点类型 | 命名规则 |
|----------|----------|
| 导线 I 串（耐张塔） | `后导X`, `跳X_1`, `前导X` |
| 导线 I 串（悬垂塔） | `后导X`, `导X`, `前导X` |
| 双挂点双联 I 串 | `后导X_S1`, `后导X_S2` |
| V 串/U 串 | `后导X_V1`, `后导X_V2` |
| 地线挂点 | 将"导"替换为"地" |
| 跳线挂点 | `跳X_Y`（X=相序号, Y=跳线串号） |

### 5.4 坐标系

杆塔坐标系原点位于最高呼高最长接腿基础平面中心，X 沿横担方向，Y 为纵向（垂直线路），Z 垂直向上。

## 6. 模型细度等级

### 6.1 几何细度（Level of Geometry）

每个参数化模型均定义几何细度表，列出驱动参数的名称、关键字、单位、取值约束。例如：
- 导地线：TYPE, SECTIONALAREA, OUTSIDEDIAMETER, WIREWEIGHT, COEFFICIENTOFELASTICITY, EXPANSIONCOEFFICIENT, RATEDSTRENGTH
- 中间接头：TYPE, L(长度), D(外径), L1(端子长度), d(内径)

### 6.2 属性细度（Level of Attribute Definition）

属性文件采用 `*.fam`，按行存储 `属性关键字=属性名称=属性值`。
分为：
- **属性信息细度**（attribute information）：描述产品的技术参数、型号、材质等
- **工程信息细度**（engineering information）：描述项目、安装、施工等信息

### 6.3 通用约束条件

| 约束类型 | 说明 |
|----------|------|
| 尺寸正值 | 所有长度/半径参数 > 0（特殊说明除外） |
| 半径关系 | 外半径 > 内半径（环形/垫片类），顶半径 > 底半径（锥台类） |
| 方向约束 | Z 轴向上，角度参数范围 0~2PI 或 0°~360° |
| 阵列约束 | 行列数 ≥ 0（0 表示无），间距 > 0 |
| 分裂数 | 导线分裂数 ≥ 1 |
| 绝缘子片数 | ≥ 1，复合绝缘子为 1 |

## 1. 导地线

**关键字**: `TYPE`, `SECTIONALAREA`, `OUTSIDEDIAMETER`, `WIREWEIGHT`, `COEFFICIENTOFELASTICITY`, `EXPANSIONCOEFFICIENT`, `RATEDSTRENGTH`

| 参数 | 关键字 | 类型 | 单位 | 说明 |
|------|--------|------|------|------|
| 型号 | `TYPE` | string | - | 导线/地线型号 |
| 截面积 | `SectionalArea` | float32 | mm² | 导线的截面积 |
| 外径 | `OutsideDiameter` | float32 | mm | 导线外径 |
| 单位长度质量 | `WireWeight` | float32 | kg/km | 每公里重量 |
| 弹性系数 | `CoefficientOfElasticity` | float32 | N/mm² | 弹性模量 |
| 线膨胀系数 | `ExpansionCoefficient` | float32 | 1/℃ | 热膨胀系数 |
| 额定拉断力 | `RatedStrength` | float32 | N | 最小破断力 |

**Go 结构体**: `TransmissionLineParams`

## 2. 绝缘子串

**关键字**: `TYPE`, `SUBNUM`, `SUBTYPE`, `SPLITDISTANCE`, `APPLICATION`, `SORT`, `VANGLEL`, `VANGLER`, `ULINKLENGTH`, `WEIGHT`, `FITTINGLENGTHLU`, `FITTINGLENGTHRU`, `FITTINGLENGTHLD`, `FITTINGLENGTHRD`, `LINECOUNT`, `LINESPACING`, `LINEARRANGE`, `RADIUS`

| 参数 | 关键字 | 类型 | 说明 |
|------|--------|------|------|
| 型号 | `Type` | string | 绝缘子串型号 |
| 导线分裂数 | `SubNum` | int32 | 分裂导线根数 |
| 分裂排列方式 | `SubType` | int32 | 双分裂: 1-垂直, 2-水平; 三分裂: 1-正三角, 2-倒三角 |
| 分裂间距 | `SplitDistance` | float32 | mm |
| 串用途 | `Application` | int32 | 1-导线串, 2-地线串 |
| 串类型 | `StringType` | int32 | 1-悬垂, 2-耐张 |
| V串夹角(左) | `VAngleLeft` | float32 | 度, 与右夹角同时为0则为I串 |
| V串夹角(右) | `VAngleRight` | float32 | 度 |
| U串连接长度 | `ULinkLength` | float32 | mm, 非U串为0 |
| 重量 | `Weight` | float32 | kg |

**金具长度** (`FittingLengths`):

| 参数 | 关键字 | 说明 |
|------|--------|------|
| 金具长度(左上) | `LeftUpper` | 左侧绝缘子串上部金具总长 |
| 金具长度(右上) | `RightUpper` | 右侧绝缘子串上部金具总长 |
| 金具长度(左下) | `LeftLower` | 左侧绝缘子串下部金具总长 |
| 金具长度(右下) | `RightLower` | 右侧绝缘子串下部金具总长 |

**多联信息** (`MultiLink`):

| 参数 | 关键字 | 说明 |
|------|--------|------|
| 联数 | `Count` | 多联数量 |
| 联间距 | `Spacing` | 两联之间间距 |

# 第三部分：基本图元（数据交互规范）

依据 T/CEC 5055-2021《输变电工程三维设计模型数据交互规范》附录 B。

基本图元（Fundamental Geometry Unit）是参数化建模的最小图形单元，每种图元由一组驱动参数描述。
图元原点均为 `(0,0,0)`，参数之间采用 1 个空格分隔，格式为 `对象名 参数1=值 参数2=值 ...`。

## B.1 球体

图元名称：`Sphere`

| 字段 | 说明 | 值范围 | 类型 |
|------|------|--------|------|
| R | 半径 | R>0 | float |

**建模要点：**
- 原点：球心
- 约束：R > 0

**Go 结构体**: `SphereParams` → 字段 `Radius`

---

## B.2 旋转椭球体

图元名称：`RotationalEllipsoid`

| 字段 | 说明 | 值范围 | 类型 |
|------|------|--------|------|
| LR | 极半径 | LR>0 | float |
| WR | 赤道半径 | WR>0 | float |
| H | 横切高度 | 0<H≤2LR | float |

| D | 导线直径 | D>0 | float |

**建模要点：**
- 坐标/向量格式：`x,y,z`（逗号分隔）
- 约束：Sag > 0, D > 0

**Go 结构体**: `WireParams` → 字段 `StartPoint, EndPoint, StartDir, EndDir, Sag, Diameter`
